# Share what you learn

**[English](#english) · [简体中文](#简体中文)**

## English

Examples, clearer methods, translations, and reproducible fixes are welcome. Start with an [issue](https://github.com/sirsws/ai-video-director/issues); a finished pull request is not required.

For a workflow or generation result, include the brief, the method you used, the platform and model, relevant settings and references, and what changed. Distinguish an actual result from an untested design.

Share materials you have permission to share, preserve source attribution, and keep credentials and personal account information private. For script changes, describe the input and validation. The detailed method library is maintained in Chinese; English explanations and translations are welcome.

## 简体中文

欢迎补充示例、改进方法、翻译内容或修复可复现的问题。可以先[开一个 Issue](https://github.com/sirsws/ai-video-director/issues)，不必一开始就提交完整代码。

分享用法或生成结果时，说明需求、采用的方法、平台和模型、关键设置与参考输入，以及哪项修改起了作用。区分实际观察和未经生成的设计。

分享有权公开的材料，保留来源与适用许可，账号信息和凭据留在本地。修改脚本时说明输入与验证方式。详细方法库目前以中文维护，欢迎英文说明与翻译贡献。
