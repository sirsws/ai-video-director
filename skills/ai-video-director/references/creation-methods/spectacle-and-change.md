# 奇观与变化：让观众经历发生过程

适用于幻想世界、尺度奇观、变形、建造/烹饪等过程，以及冻结、倒流等时间玩法。先决定值得看的是规模、变化方式、中间过程还是不同时间状态的关系；无需为了成立而额外加世界观说明或戏剧代价。组合遵循[方法使用](../creative.md#method-use)。

<a id="scale"></a>

## 尺度与世界如何被发现

“大”“史诗”“震撼”需要参照与观察路径。可用熟悉物、人物体量、层层空间、跨越所需时间、被影响的环境，让观众读到尺度。人物并不必须一直在画面中央；小人物、远景活动或地标可以持续提供比例。

选择一种展开关系：从可理解的局部逐渐看到整体；沿主体路径穿过内部结构；先看环境受影响再见来源；先建立常态再让巨大实体经过。摄影移动应该真的揭出新部分，不能只围着同一静态表面转圈。

幻想实体各有具体作用：桥是通过路径，鲸群遮住日光，楼宇漂移改变人物行进，裂缝让另一空间露出。允许多个奇观，只要它们之间有可读关系；不是所有片都要限制为一个爆点。画面很大时仍要给注意力路线，见[环境展开](../techniques/camera-foundations.md#environment-tour)。

<a id="dense-group"></a>

### 密集群体奇观：以万剑为例

当大量同类物件本身就是主要看点时，先在方案中建立群体覆盖的空间、前中后景的层次，以及汇聚、交错流转或卷成风暴的整体形态，再让起剑、变阵、齐射等选定动作承接这片群体。镜头仍可从局部进入整体，设计时的主次不规定出场顺序。

规模要有可见依据：占满人物周围或场地上方，前景物件巨大且短暂遮挡，中层结构清楚，后层密集延伸，让人物或地标提供参照。数量词与这些覆盖、层次和运动相互配合，避免前段“只有几把”“其余留在原处”等要求无意压小后续群体。

可选写法：

```text
密集的实体长剑占满人物周围及头顶空间，前后错落、彼此交叉地流转。近处剑身巨大且失焦，中层刃口与反光清楚，后层密集剑影延伸入暗处；人物从中央空隙露出，剑群逐渐卷成高耸、密集而持续运动的风暴。
```

同一方法可用于箭雨、无人机群或鱼群，覆盖范围、密度、材质与运动方式随本片改变。万剑的暗调影像可另选[港式奇幻武侠风格示例](../techniques/look-and-effects.md#dark-hong-kong-wuxia)，群体方法与影像风格分别调用。

此例提炼了设计应用中的覆盖、层次与数量取舍，不构成密集群体的稳定复现保证；其他主体与场景仍需看本次实际结果。

<a id="process"></a>

## 制作、改造与连续变化

先明确初态、目标状态，以及真正值得观看的中间变化。固定比较锚点可以是桌面、建筑轮廓、材料边缘或人物动作，不等于相机必须固定。

| 过程方式 | 该写清什么 | 常见误用 |
| --- | --- | --- |
| 连续物理改变 | 变化从哪里起，怎样传播，结构/材料怎样响应，哪些身份特征延续。 | 只写“变成”，用闪光把整个过程藏掉。 |
| 有选择的过程蒙太奇 | 每段完成哪一步、留下何种状态，下段接着改变什么。 | 每切都从空桌开始，或只展示多个完成图。 |
| 时间压缩 | 哪些对象加速成长/移动，哪些比较锚点持续可辨，摄影路径如何延续。 | 所有人与环境一起无差别快动，失去要看的差异。 |
| 部件重组 | 哪些部件松开、折叠、滑动、接合；原部件怎样成为新结构。 | 生成端凭空换成另一对象，承诺的机械过程未出现。 |
| 材质改变 | 哪些表面/内部改变、形状和动作是否保持、光和接触怎样显示差异。 | 材质变了却同时无意换形、换身份或回到初态。 |

烹饪不一定只能拍手，建造不一定不能移动机位；选择观察谁、怎么做和材料怎样变化。具体实现调用[时间与特效](../techniques/spacetime-effects.md)、[材质显现](../techniques/look-and-effects.md#material-response)。写实产品的内部结构和功效仍要有依据，幻想设计明确是虚构选择。

<a id="time-control"></a>

## 冻结、极慢与倒流

先确定不同对象各自的时间：世界停住而人物活动，主体极慢而相机正常，部分物件倒流而其他继续，或某种变化沿空间传播。冻结不是全部拍成一张静图；相机、声源或豁免对象可以继续提供过程。

选择触发与观察内容。停住的水珠、布料、坠落物和人物姿势要有明确状态；环绕或穿行时，观众应能读到它们是同一空间里的对象。恢复时交代从哪里继续，不突然回到触发前。倒流要说明回到哪个状态、经过哪些重要逆向过程，不能仅说“时间倒转”。

普通→峰值→冻结→探索→倒流是一种可选组合，作品可只用其中一段。豁免对象可以不止一个，声音也能与视觉不同步；这种差别需要明确的听觉安排。技术看[空间冻结](../techniques/spacetime-effects.md#freeze-space)、[极慢观察](../techniques/spacetime-effects.md#bullet-time)、[局部逆向](../techniques/spacetime-effects.md#local-reverse)。

## 原创示例：折起来的街道

修士沿空街推着一扇木门前行。门框每经过一段街面，那段青石路就沿砖缝向上折起，带着两侧店铺像书页一样竖起；镜头从门内向后退，先看见他推门的身体发力，再从侧上方越过门框，看到街道正一页页合拢成巨大的折扇。招牌、晾衣绳和灯笼随各自街页移动，木铰声和石板摩擦连成节奏，远处仍未折起的一段街成为尺度参照。

此例的回报是空间折叠怎样传递；必须保留触发、折缝、承载物与相机揭示，不能缩为修士站在一把巨扇前。若用户只要变形展示，可不补人物目的；若要喜剧，可把最后一页卡住导致的后果交给[喜剧方法](comedy.md)发展。这是原创未生成示例。

## 组合时保留各自贡献

与音乐组合，让变化在乐句节点发生，仍保留可读中间态；与动作组合，让地形/材料变化改变实际路线；与生活观察组合，可由可靠的拍摄位置慢慢发现异常。不要为了“更真实”消除已经选定的幻想机制，也不凭空增加规则说明压过观看。

失效定位看：只有结果没有过程、规模缺参照、相机移动没有揭新信息、变化后无故复原、冻结对象仍按正常时间移动、倒流没回到约定状态。尚未生成时只能检查输入是否说明这些关系，不能保证成片执行。
