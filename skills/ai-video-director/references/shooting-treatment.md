# 拍摄处理：场面、整体风格与段落

在[作品创作](creative.md)中，需要比较一场怎样拍、如何让摄影/光色/声音配合，或如何安排段落与结尾时读对应部分。已经有充分拍法则沿用，不把本页变成每片必须重填的导演表。

类型机制查[方法入口](methods.md)，具体实现查[技法索引](techniques/INDEX.md)。本页提供跨方法的组合与取舍。

<a id="scene-treatments"></a>

## 场面与整体处理

### 从作品目的推导整体处理

用一句话确定具体导演意图，例如“观众先发现他在掩饰，再等待对方是否看穿”，或“让观众看清双人的脚步怎样互相带动，感到越来越投入”。“电影感、震撼、高级”不能单独作为意图。

按 **意图 → 观看位置与信息先后 → 行动和表演 → 相互配合的视听选择 → 各镜头任务** 推导。先判断观众需要接近人物、观察关系、追踪动作，还是欣赏空间与材质，再选择拍法；已有明确运镜时，发展它所揭示的实际事件；新增手法要有具体作用。

已有导演或作品参照时，沿用其中明确要借的具体作用；尚未选定时，根据创意选择整体处理或具体参照。参照的读取、改编比较与记录按[参考选择与改编](reference-adaptation.md)执行。

选中案例或用户原稿已有充分的镜头、表演、光色与声音安排时，直接作为本片设计承接，只补适配后出现的缺口；无需先拆散再按统一表格重建。借整体拍法时保留各手段的组合关系，只借局部时不扩张其用途。导演设计仍须成立，但不以新增镜头、细节或改写量证明完成。

### 视听手段怎样共同工作

观看位置、身体调度、表演尺度、光色、声音与切点的相互影响，按[共同发展声画](creative.md#用同一方案共同发展)落实。歌词、对白与字幕同时抢注意时，重新安排时机或声部。

具体方法按[方法调用规则](creative.md#method-use)取用。

声画反差、静镜头中的强表演和调性转向可以服务同一导演意图。说明并置怎样起作用；各手段彼此争抢或抵消时，调整它们之间的关系，不默认全部变得克制。

### 按场景任务选择成套拍法

先找与本段实际任务相符的起点，再按人物、空间与整体风格调整。一个作品可经过多个任务，不要求每段都套表中同一行。

| 场景任务 | 成套处理起点 | 表演或动作重心 | 常见失败与调整 |
| --- | --- | --- | --- |
| 亲密对白／潜台词 | 中近景或近景保持人物与对方关系，平视或肩后，克制移动；光线让眼神、手与物件可读，声音留出呼吸和停顿。 | 目标与语言不一致时，用一次停顿、重复动作或距离变化露出差距。 | 漫游镜头和频繁切镜打散表演；先保住完整反应，再决定是否需要切近。 |
| 对抗／控制权变化 | 对置视角与站位表达谁占据空间，距离随攻防改变；高度、遮挡、光色可强化差异；变化节点才改观看位置。 | 谁逼近、谁让步、谁停止或改变策略；强势也可以通过不动表现。 | 对称构图抹掉关系，或双方仅对视不采取行动；让具体行动改变对方和空间。 |
| 揭示／发现 | 先确定观众与人物谁先知道，通过构图、遮挡、运镜、声音或光线显露信息，再安排识别反应。 | 看见、认出、误认、确认是不同阶段，选本片真正需要的阶段。 | 开场参考图已经泄底，或揭示后没时间理解；调整参考状态与揭示时机。 |
| 决定／转折 | 取景让选择者、选择对象和关键动作可读；推近或保持可集中注意，其他声部可让出瞬间。 | 用会产生后果的行动完成选择，如放开、交出、签下、跨过。 | 只有宣言没有执行，或切镜跳过动作；保留决定发生的可见过程。 |
| 抵达／建立世界 | 远景或中远景建立主体与空间，通过环境光、空间声和有目的的运动揭出地形、规模与路径。 | 姿态、步速、进入方式让人物在世界中的处境可读。 | 只有空景和随后摆拍；让建立空间同时支持人物行动或发现。 |
| 追逐／动作 | 先定目标、路线和方向，用跟踪或手持获得运动体感；剪辑保留接近、接触、避让与后果，声音加强重量和节奏。 | 身体发力、失衡、恢复、借力或差一点碰到，说明动作代价。 | 同时叠加多种运镜与微动作造成混乱；优先固定观看侧或拆开揭示任务，不先删核心动作。 |
| 变形／特效 | 稳定或受控的观察关系让前后差异可比；按变化过程安排光影、遮挡、接触与环境响应。 | 什么先改变，变化怎样传递，主体如何回应，结束后保留什么。 | 只写“变成”或靠切镜换结果；补变化载体、过程和完成证据。 |
| 喜剧时机 | 干净的空间关系，先建立观众预期，再用动作时机、反应或延迟显出偏差；固定镜头和干脆声音可作起点。 | 人物认真执行自己的目的，行为与结果形成反差。 | 镜头忙于炫技、提前提示笑点、回报一闪而过；调整信息顺序和停留。外放喜剧按自身尺度处理。 |
| 情绪低点／疏离 | 距离、空白、停留、环境声或稀疏声音让人物处境可感；近距离也可让观众无法回避。 | 压住、回避或无法继续的具体行为，只有本片需要时才采用微小表演。 | 用泪脸和上涨配乐代替处境；让行为、物件或人与空间的关系承担情绪。 |
| 产品主视觉／功能证明 | 从用途或整体进入关键结构、操作或材质，受控运动与主光显出真实区别，身份、形状与标识保持一致。 | 使用动作、材料响应或前后对照本身提供证据。 | 围着产品转却看不到价值，光斑遮住标识；改观察面、操作与用光。 |
| 舞蹈／身体表演 | 按[身体任务与专业表演](techniques/performance.md#non-narrative-performance)确定身体段落、相互位置和节奏，再选取景；叙事中的人物目标由同一段动作承载，纯欣赏不另加冲突。 | 连续动作、节奏差异、共同表演与空间变化。 | 特写裁掉关键动作、远景看不清关键表情或局部发力，或群体被压成单人主动作；按各段观看重点调整取景，让关键动作、表情与人物关系在需要时可读。 |
| 非叙事观察／感官体验 | 选择观察位置、持续时间、光影与声音层次，允许停留在一个状态中结束。 | 被观察对象的运动、纹理、节奏、微小变化或持续存在。 | 为填表编造冲突和反转；回到创意已定的体验与拒绝项。 |

真实产品或标识需精确保留时，按最终观看大小对照原资产中要求保留的关键结构、字形（如有）、顺序、颜色与轮廓；看似可读的替字仍是不符。先定位是取景遮挡、输入依据不足还是生成结果变形，再按当前可用能力选择修法；不把漂亮的概念图称为真实产品精确还原。尚未生成时核对输入是否足以表达，不能记作成片已通过。

<a id="style-treatment"></a>

### 贯穿本片的处理与取舍

把参照落实成摄影、光色、节奏与表演之间的一组约定，写进本片整体处理并沿用。可从下列六种组合起步，也可根据具体导演或作品建立自己的组合；不是新增六个必须选择的标签。

| 处理方向 | 摄影 | 光线与色彩 | 剪辑、声音与表演 |
| --- | --- | --- | --- |
| 观察式自然主义 | 观察位置可信，固定或轻微跟随，少打断真实过程 | 可解释的环境光，按场景保留肤色与材质关系 | 较完整的行动，环境声在场，表演像人物正在做事。 |
| 构图严谨的古典处理 | 明确构图、空间层次，移动有节制 | 有造型的主光、受控色彩和美术关系 | 切换与行动对应，表演准确，声音层次清楚。 |
| 强动感与身体冲击 | 贴近行动，跟踪、手持或快速转向有具体目标 | 明确明暗结构与轮廓，色彩服从身体和环境 | 节奏有力度，发力、碰撞、呼吸与恢复形成过程。 |
| 强表现与风格化 | 大胆构图、设计性运动与尺度变化 | 鲜明主色、戏剧光线或自洽的舞台规则 | 音乐性强，动作外放，人物与世界共同参与。 |
| 亲密极简 | 靠近人物、少量移动，关键处保持 | 少数光源和克制色彩，关键表情可读 | 少切镜，细微行为与呼吸有空间，静默有具体作用。 |
| 图形与形式感 | 固定或精确运动，几何、比例、重复与对齐 | 清楚形状、限定色彩、明确材质差异 | 节拍准确，冷面或风格化表演，声音与形式呼应。 |

一致性允许变化。需要转换、混合或打破已建立的规律时，写清从哪种关系变到哪种关系、触发点是什么、哪些辨识线索继续保留；不把每镜头重新换一套风格当作丰富。

把过程及其时间安排写入对应镜头，需要发展过程或分配用时时读取[整片节奏](techniques/process-and-rhythm.md#rhythm)与[动态组织与反PPT](techniques/process-and-rhythm.md)的相关正文。

按观看重点安排人物、活动与环境的占比，不因竖屏或主角身份默认放大、居中或持续留框。承担识别、情绪与回报的造型、道具、环境变化属于表达本身，不因新增就当作装饰。

有实质取舍时，先指出原过程靠什么行动、信息与回报关系产生价值，再比较改法。删减或重排必须由新的声画安排承接原作用；无法承接就换拍法，主动改换主要体验则回到同一作品方案核对已定要求。

幻想可通过事件本身成立，无需额外解释原理。写实程度、夸张与物理变形按观看效果选择；关键接触、受力或空间关系承担主体验时，须能让观众读懂。

## 场面调度与表演

作品需要环境承担辨识度、氛围、规模或行动条件，而用户没有锁定地点时，主动选择或构建最适合事件的具体区域。现实、历史、架空或幻想地点均可；用明确的空间身份、视觉线索与方位关系帮助生成模型稳定理解场景、让观众建立位置感，并为当前过程提供所需的路径、地形、建筑或其他环境条件。跨场景时明确各场景及切换节点，让切换实际改变时间、空间、信息或行动条件，并为新场景留出建立必要关系的画面。

当主体验依赖空间关系、运动或规模时，先确定人物、动作目标与主要事件的相对位置。区分场内行动范围与镜头揭示范围，需要移动时再安排路线。方向描述应明确参照；多人依次通过开口或边界时，确定通过顺序、开口朝向，以及人物和摄影机各自的接近路径。场景参考视图与视频取景分别选择，参考图的边界和所呈现的状态不自动限定整段行动。空间移动应推进本片的行动、信息或感受，路线可通行本身不证明值得观看。

<a id="cross-scene-traversal"></a>

### 跨场景穿行

当需要通过行进呈现长距离或大范围空间时，把多个不同场景组织成一段持续向前的行程。主体在各处持续前进，沿途场景不断更替，让观众感觉穿过了很大一片空间。

各场景应有可辨的空间差异。切换到下一处时承接前进方向或动作趋势，让新场景成为行程的继续；中间路程可以省略，按本片选择切镜或连续穿越。跟拍、景别与机位变化配合这条行进主线。

检查各场景是否接成了持续行进的过程，以及场景更替是否扩大了穿行感。地点数量、镜头运动或景别变化本身不能代替这一效果。

<a id="segment-design"></a>

## 按镜头或连续段落展开

按实际镜头或有独立观看任务的连续段落，在同一作品方案中定清下表涉及的决定；已有连续声画过程直接沿用。全片共同项放在整体处理中，各镜只补本镜内容与变化。段数、镜头数和逐秒动作不固定，关键过程不能因“允许自然变化”而省略。焦距、速度、光比和器材等参数仅在影响本片效果或本次要求明确时确定，影响观看的决定不留给编译另选。

| 项目 | 需要解决的决定 |
| --- | --- |
| 镜头／段落与用时 | 所处位置、粗略时段或相对时长；明确是切镜还是同镜内变化。 |
| 任务与证据 | 这段让观众看懂或获得什么，靠哪个可见／可听过程证明。 |
| 开始状态 | 第一幅可读构图，人物、物件、动作与声音的初始状态。 |
| 主体过程与表演 | 谁做什么，对谁或什么，关键动作、反应、表演尺度及必要衔接。 |
| 摄影 | 景别、观察侧与高度、透视感、景深／焦点、稳定方式、运动或保持、主体关系。影响效果的选择必须定下，不强填机型或数值参数。 |
| 光色与美术 | 主光及方向、明暗与软硬、主要色彩、关键材质和必须可辨的内容；继承整体设定时只写本镜变化。 |
| 声音与文字 | 对白／演唱、音乐、环境与效果声怎样落点，哪些文字何时出现、放在哪里。 |
| 结束与衔接 | 结束构图与状态、结尾用途、下镜如何接入，必须延续的动作和声音。 |
| 参考与风险 | 哪份输入控制哪项，必须稳定的身份、手部、道具或文字；已验证什么，什么仍依赖生成。 |

先在设计中解决“在哪里、怎样发生、怎样拍到、何时切换、怎样接上”，再编译视频提示词。编译或素材核对发现缺口时，直接修正本方案中的相关设计并同步正文；会改变观看效果的取景、动作、衔接或声音，不能混作措辞润色。

<a id="endings"></a>

## 进入点与结束点

按主要吸引力选择进入点，明确第一幅可读画面与第一层声音。可以从行动进行中切入，但观众必须获得理解本段所需的最少关系，不用额外铺垫挤掉主过程。

结尾先确定用途，再决定保持、停住、继续或切走：

| 结尾用途 | 需要留下的状态 | 容易失效的地方 |
| --- | --- | --- |
| 独立完成 | 行动或体验已充分兑现，观众能看清结果；可收束或让不影响理解的活动延续 | 关键后果尚未读到就结束，或回报已结束又拖出无作用尾巴。 |
| 继续同一过程 | 人物、动作、目光、摄影机和环境声保留明确的进行方向与阶段 | 提前停住、回到中性姿势，下一段只能重新启动；续接时还需实际采用素材的结束状态。 |
| 循环 | 开头与结尾的位置、动作相位、运动方向／速度、曝光和声音能够接合 | 只有构图相似，动作阶段或节奏不匹配；为“安全”减速停住反而形成顿挫。 |
| 主体／文字保持 | 主体、功能结果、标识或文字无遮挡，留足辨认时间 | 尾部继续漂移、遮挡或形变，最需要看的东西反而读不清。 |
| 剪辑接点 | 动作、信息或声音在明确边界上交接，下一镜有可承接内容 | 只截断动作却没定义接点，或声音突断造成无意跳跃。 |
| 揭示／笑点／冲击 | 主要回报落在明确节点，并有足够时间或声音让观众理解 | 机械地把回报压在最后一帧，刚出现就没了；不等于越晚越好。 |

不规定所有结尾都静止或都运动。额外铺垫、停留与收尾按[整片节奏](techniques/process-and-rhythm.md#rhythm)比较其作用与占时。
