# 动画媒介：二维、三维与定格的运动

纯二维、手绘、剪纸、界面动画、三维卡通或定格作品需要选择媒介自身的运动方法时读取对应小节，调用遵循[方法使用](../creative.md#method-use)。二维与写实合成的混合影像按[同镜混合媒介](look-and-effects.md#look-system)分配人物、环境和覆盖层的表现，不设“永远不能使用镜头词”的禁令。烟、液体、粒子等的来源、路径与残留采用[特效与实景联动](spacetime-effects.md#effect-interaction)，再按本片画法呈现。

<a id="two-dimensional"></a>

## 从观看任务选择布局和运动

先明确媒介、角色或产品的轮廓、背景绘制与色板，再决定哪些层保持，哪些层移动或变化。不要仅把“写实”替换成“动漫”，仍照搬全部实体镜头、景深和体积光要求。

| 任务 | 可用方法 | 需要确定什么 |
| --- | --- | --- |
| 保持主体、展开环境 | 背景滚动，多层前后景以不同速度移动 | 每层是什么，方向和相对速度，主体在画面中的位置；不能由背景滚动伪造本应发生的主体操作。 |
| 让一次动作有起伏 | 准备姿态、快速动作段、保持帧、余动 | 哪个节点需要看清，哪段可迅速通过；保持是表现选择，不因“反PPT”一律取消。 |
| 强化撞击或高速轨迹 | 冲击帧、速度线、拖影变形 | 插入在哪次真实动作上、变形范围、何时恢复辨识；功能证据不能被效果盖住。 |
| 沿画面探索 | 在背景画稿上横移、上下扫描或推进，图层视差 | 起止布局、被揭露的内容和连续路径；摄影词能准确表达有意混合效果时可以保留。 |
| 组织绘制节奏 | 一拍二等间歇运动、重点段更连续的动画 | 适用段落与观看作用；这是设计语言，不保证生成端严格执行帧率。 |
| 塑造光色 | 两阶阴影、轮廓色块、画出的高光、限定色板 | 光影作为图形怎样变化、保留哪些轮廓；纯二维不默认加写实焦外和镜头呼吸。 |
| 界面浏览／选角确认 | 区分固定布局、可变内容与交互状态 | 每次移动焦点或确认时，区分当前浏览项与已确认项，让各自所用的高亮、对象、标签与声画反馈指向对应选项。确认后按观看重点安排主体动作与所需的界面退场，分时或协同均可；只有用户已确定由后期处理的精确文字或布局，才说明相应分工。 |

声音按媒介和本片选择：拟音、音乐重音、风格化音效或静默均可；拖影配掠声、保持帧留出呼吸只是选项，不把二维一律配成夸张卡通声。

## 转成连续过程

用“哪一层、什么形状、怎样移动或变化、落在哪个布局”写过程。人物动作仍保持意图、支撑与回应；产品演示仍须有已知功能依据。未提供的内部结构不因采用动画就变成事实，可选择能证明已知功能的观察方式或说明需要补充的信息。

示例：平涂纸偶人物推开画面中的折叠屏风，近景屏风层向两侧移动，后面的彩色街道逐层显露；人物身体停在伸臂姿态，衣角再摆一下落稳。关键是屏风确实让出视野；仅背景变色不能替代打开动作。

跨镜或跨段延续角色画法、线宽、色板、图层角色和运动方向；后段布局依据实际采用结果。变形后的角色或产品按[结构后态](spacetime-effects.md#structural-change)继续，不在切镜后无故复原。

## 失败时定向修正

- 跑向写实或三维：核对是否混入了无意的摄影成像要求，明确绘制背景、平面色块和阴影方式；有意混合部分保留。
- 漂浮、拖沓：检查关键姿态、动作爆发、保持和余动的分配，避免所有图层匀速漂移；不能只加“流畅”。
- 快速动作中轮廓难辨：把部分速度表达交给轨迹、背景或短暂拖影，关键身份和操作节点保留清楚姿态；减少细节可能损失表演，应说明取舍。
- 镜间画风跳变：核对媒介、线条、色板和图层处理有没有被重写，有意转变则给出触发与继承项。

这些方法用于设计和诊断，不证明特定生成模型必然怎样理解词语。完整示例见[二维产品过程](../examples.md#animation-example)。

<a id="three-dimensional"></a>

## 三维卡通：体积、材质与身体尺度

先确定角色轮廓、体型比例、材质和关节活动方式。大头短肢、柔软无骨或硬壳机械会改变伸手距离、支撑点、惯性与表情范围；不要给所有角色套同一套真人动作。身体变形可以夸张，但变形的起因、极值和恢复要服务表演，关键配饰与辨识线索在运动中仍可追踪。

材质需要在动作里出现：毛发随转向滞后，塑胶肚皮被挤压后回弹，木质关节在转身时分段活动，金属外壳先受光再显出凹陷。光照可为体积服务，边缘、反射和接触阴影也可让角色落在环境里；“三维卡通”不自动等于某一知名IP或统一幼儿可爱风。

表情可以由全身表达：惊讶时重心后移、双手张开和耳朵立起共同发生，开心时连续跳步、摇尾和转身可以保持完整过程。若本片就是细微表演，也可选小幅动作；不按媒介一律强制大幅或微动作。多个角色可以共同运动，按[群体表演](performance.md#group-performance)分配注意。

原创示例：木头小厨师用过长的搅拌勺搅汤，身体被勺柄带着沿锅边走圆圈，脚掌每次落下发出木敲声；他跳上凳子终于稳住勺柄，锅中旋涡仍继续，帽子被蒸汽托起。短腿与长勺共同形成过程，不是站着做惊讶表情。这里描述的是拟人设定，未生成验证。

<a id="stop-motion"></a>

## 定格与步进：选择哪些运动断续

手作质感与运动节奏分别决定。材质可以是黏土、毡、纸、木偶或混合物；指痕、切边、纤维和微小形变应保留到有用的程度。定格的姿势停留与跳步是有意表现，不因为“反PPT”就把它全部改成连续平滑运动。

先找关键姿势与动作连接：准备、发力、经过、接触、回弹和余动。姿势间变化要形成方向与重量，不能只是几个彼此无关的摆拍。可以让角色步进、烟和纸屑更连续，也可以让环境与主体都跳步；说明各自的节奏与关系。

相机固定、分步移动或平滑跟随都可以与定格结合。选择平滑相机时，背景视差连续而角色姿势断续，是有意的层次；选择相机也步进时，明确沿同一路径变化，避免被误解为无关切镜。“一拍二”或“低帧率感”是设计描述，不是平台实际输出帧率保证。

原创示例：黏土赛车在纸板街道间跳步前进，轮胎每次触地略微压扁，路旁薄纸招牌分两次回弹；摄影沿街平滑侧跟，前景窗框连续掠过，形成机器行驶与手作步进的对照。声音可用细小卡嗒和轮胎摩擦，不必须禁配乐。此例保留运动相机，不因定格媒介先行删除。

若动作只剩漂移，补关键姿势与受力；若手作材质被渲成光滑塑料，核对材料与表面作用；若平滑和步进混得无意，明确哪些对象采用哪种节奏。只有真实结果显示的问题才叫执行失败，尚未生成的组合不因此被判不可做。
