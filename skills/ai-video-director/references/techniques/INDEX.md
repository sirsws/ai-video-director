# 视听技巧索引

拍摄设计、编译和返修共用。按[方法调用规则](../creative.md#method-use)承接已有充分设计，用下表定位本片需要新设计、适配或补足的部分；读取相关正文，不因列有条目就逐项增加要求，也不等出现失败再读。

整套摄影、光色、表演、声音怎样配合，由[拍摄处理](../shooting-treatment.md#scene-treatments)负责；跨部门[六种风格组合](../shooting-treatment.md#style-treatment)也在那里。多个生成片段的采用状态和后续任务由[连续接续](../sequence-and-continuation.md)负责，实际多版本的共用段与独有段也在那里安排；下表的跨镜连续用于镜头内部和镜头之间的具体方法。

## 分镜与镜头组织

| 当前要解决的问题 | 方法与作用 |
| --- | --- |
| 将已选创意展开为分镜，确定每镜任务、用时、视听安排和承接 | [逐镜头形成连续视听方案](../shooting-treatment.md#segment-design)：沿用同一作品方案，不另建分镜交付文件。 |
| 选择一镜到底、多个镜头或蒙太奇，区分切镜与同镜内阶段；独立素材需要取舍、排序和连接 | [剪辑、覆盖与观看方向](editing-and-continuity.md#editing)：按观看任务选择结构及各段作用，再决定切点与取景。 |
| 结尾用于完成、接续、循环、展示或揭示，应留下什么状态 | [进入点与结束点](../shooting-treatment.md#endings)：分别核对动作、摄影和声音的结束用途。 |

| 需要确定最终画布、活动画面、身体边界与焦点 | [画布、构图与焦点](camera-foundations.md#framing) |
| 需要选择机位高低、距离、主体画幅占比与前后层次 | [仰拍／俯拍／空间比例／框景](camera-foundations.md#viewpoint) |
| 从汽车后备箱内部向上看人物，让箱口形成近处框景 | [后备箱内部仰拍／昆汀式后备箱视角](camera-foundations.md#trunk-shot)：安排箱盖状态、人物俯视与箱内取放任务；固定机位也可成立。 |
| 需要通过运镜或不同视点，显露场面规模、内部活动与环境层次 | [场面展开与环境游览](camera-foundations.md#environment-tour) |
| 保持向下观察，让场面排列围绕画面中心转动 | [垂直俯拍旋转／顶视旋转](camera-foundations.md#overhead-roll) |
| 机位固定，放大细节或扩大取景范围 | [原地变焦／Zoom](camera-foundations.md#zoom) |
| 清晰度从对象A交给对象B，前后方向可选 | [拉焦／Rack Focus](camera-foundations.md#rack-focus) |
| 人物在画面中稳定，环境运动带出体感 | [身体相对固定](camera-foundations.md#body-relative) |
| 自拍、镜面或手持第一视角，需要核对谁拍谁、设备支撑与手部任务 | [机位与构图](camera-foundations.md#framing)；涉及持机、牵手或交接时读[动作与空间衔接](action-and-staging.md#continuity) |
| 第一视角连续穿越空间 | [FPV连续穿越](camera-foundations.md#fpv) |
| 人物大小基本不变，背景逼近或远离 | [滑动变焦／希区柯克／Dolly Zoom](camera-foundations.md#dolly-zoom) |
| 近远对象对齐制造错觉，改变视点揭露实际空间 | [透视错位与揭穿／Forced Perspective](camera-foundations.md#forced-perspective) |
