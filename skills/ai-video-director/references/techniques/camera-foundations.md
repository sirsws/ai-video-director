# 机位、运镜与视点效果

按[方法调用与复用规则](../creative.md#method-use)读取本片相关小节，已有充分决定直接沿用；据此按本片观看任务选择拍法。

<a id="camera-move"></a>

## 运镜与取景

| 拍法 | 适合承担的工作 | 设计时交代清楚 |
| --- | --- | --- |
| 固定 | 保留表演、喜剧等待、精确操作、身份与标识、可比较的变化 | 固定的是摄影机，不是人物；画面内什么在变化，何时完成观看任务。 |
| 推近／拉远 | 接近认知或情绪，揭出背景、规模或人物处境 | 摄影机是否真实位移，起止距离和取景、沿途遮挡；变焦则明确为焦距改变，不混写。 |
| 横移／跟踪 | 行进、双人走位、舞蹈、前景层次或侧方揭示 | 摄影机与主体谁快谁慢、从哪侧跟、是否转向、何时显出侧方内容。 |
| 摇摄／俯仰 | 保持位置而改变观看方向，接住声音或动作引发的关注 | 起止朝向、经过什么、何处停住；不把转向误写成位移。 |
| 环绕 | 展示体积、关系或人物姿态，改变背景层次 | 围绕谁、哪段弧线、角度变化后看见什么；只有单一正面参考时评估侧背面依据。 |
| 升降／高位移动 | 显出地形、层级、规模或全局关系 | 高度和俯仰怎样变化，关键人物何时还能辨认；不同时依赖远处微表情或小字。 |
| 手持／贴身跟随 | 现场感、冲击、身体努力或主观不稳定 | 晃动幅度与主体可辨度，关键动作处如何保持读懂；不是全程随机抖动。 |
| 拉焦 | 两个已建立对象间的注意交接 | 两者相对距离、焦点从谁到谁、触发点；复杂运动同时发生时先解决对象位置和焦点可追踪性。 |

每次运镜先定起始观察位置与方向、位移／转向及速度、途中显露的内容、结束取景，并与主体路线共同核对。需要展示侧方人物或相连区域时，使用[场面展开与环境游览](#environment-tour)。固定机位、一镜到底或多镜头由观看任务决定。

```text
从〈观察位置与起始取景〉关注〈对象或活动〉。摄影机〈保持或改变位置〉，视线〈保持、转向或追随〉，以〈速度与停顿〉呈现〈需要看清的过程或关系〉，结束于〈取景与动作状态〉。有动作或声音引导观看变化时，写入对应节点。
```

<a id="emotional-push-in"></a>

## 情绪推近／斯皮尔伯格式推近

人物察觉、理解或承受某件事时，让摄影机缓慢接近，将身体与环境中的反应逐步集中到面部。先确定触发事件、人物看向哪里、表情怎样变化，再安排推近的起止取景与停留；途中保留理解反应所需的环境信息，最后给观众读清表情的时间。

这里的“斯皮尔伯格式推近”是用户参考片的检索别名：片中称“闯入式”，实际描述的是摄影机向人物推进。人物在画面中随推近逐渐变大；主体大小基本稳定、背景纵深变化的拍法见[滑动变焦](#dolly-zoom)。由另一个主体突然进入近前景接管注意力的拍法见[前景闯入](staging-and-reveal.md#foreground-entry)，两者分别检索。

```text
〈场景与人物正在进行的活动〉。在〈触发事件〉发生时，人物看向〈明确方位或对象〉，从〈初始反应〉逐步转为〈可见的表情或身体变化〉。摄影机从〈起始距离与景别〉沿〈接近路径〉缓慢平稳推进，人物在画幅中逐渐变大，焦点跟随〈面部或眼睛〉，停在〈结束景别〉；保留〈必要环境线索〉，停留至〈反应的完成点〉。
```

参考：[用户提供的运镜示范](https://www.douyin.com/video/7703871643310918946)，约9—14秒的画面与字幕；据此整理的方法写法，未在本项目生成验证。

<a id="framing"></a>

## 画布、构图与焦点

以本片选定比例为最终画布，按观看需要选择满幅、内嵌画面或分屏，并确定活动画面的大小、位置、边界与切换时机。选择比例时比较人物辨识、横向关系、纵向动作和环境展开各需多少画面空间；原生横幅可直接使用入口支持的横向比例，内嵌横幅则属于另行设计的画面布局。比较人物和关键动作的实际占比，不因横幅更宽就假定人物更大，也不在裁切问题出现时只靠退远解决。

内嵌横幅示例：本片若选择9:16画布并需要固定遮幅，可在中央保留2.35:1活动画面，上下黑色遮幅边界固定；运镜、切镜与人物动作均在活动画面内组织。构图需容纳本段必须看清的身体与道具，字幕区也按整个画布确定。

已有稿改画幅时，按新边界复核主体占比、动作路径与关键接触点，以及分屏、遮幅和字幕布局；只调整受影响的取景与承担该构图的参考输入，按[局部返修](../production-and-delivery.md#local-revision)保留其他有效安排。

先确定观众从哪里看、关注什么、关注如何转移，再按下节选择景别、观察侧、高度、透视、景深与焦点。把“拍全身”“拍手部”“看见两人关系”落到实际边界：头、脚、接触点、行动目标、前后环境哪些要同时入画，哪些可先后建立。浅景深时说明谁清楚、谁虚化；拉焦写清前后对象和触发时机，不能让关键手部与面孔都处于失焦层。

机位名称不替代空间安排。多人互动或对抗时，核对身体朝向、视线与动作目标；具体手别、持物侧按人物自身左右与靠近／远离对方的关系定义，再核对画面呈现。主观或观察式拍法要体现寻找、发现、确认或欣赏的过程，第三人称也可采用。

设计依赖实际设备的拍法时，先明确谁拍谁，以及设备由手持、支架或身体固定等哪种方式支撑；只有实际占手时，才把持机纳入牵手、拿物等任务，核对同手任务是否兼容。需要松手、换手或设备交接时，把支撑转换写进动作衔接，使镜头运动与支撑方式及其转换相容。主观视点本身不要求有人持机，设备也不必入画。

镜面拍摄不要用“镜像左右互换”直接推定哪只手在画面哪一侧；画面对应关系还取决于拍摄方向及是否额外水平翻转。无需锁定画面左右时，写清人物自身手别与连续可见的交接即可；确需锁定时，依据实际取景或反射关系核对。

<a id="shot-selection"></a>

## 景别与镜头选择

按本镜必须读到的证据选择取景，不把某种景别固定配给某种情绪：

| 观看任务 | 可选取景与收益 | 需要核对的代价 |
| --- | --- | --- |
| 看规模、地形、抵达或整体排列 | 大远景让主体与环境建立尺度关系 | 关键人物须可定位；转折若靠微表情或小字，需另给可读证据。 |
| 看全身动作、舞蹈、多人调度或人与环境的作用 | 全景保留脚点、路径、距离与行动回应 | 需完整看清的身体部位与关键接触点不能被遮挡或裁掉；动作可以复杂，但观众要能跟住关键关系。 |
| 看对话、交接、产品使用及身体与面部的联动 | 中景把人物反应和手边行动放在一起 | 确认所需手部、物件和反应者同处有效画面；中景不自动保证双手入画。 |
| 看表情变化、口型、物件细节或一个关键触点 | 近景／特写集中注意力 | 必要的空间关系须先建立或在画内保留；大幅运动要有相应跟随、构图余量与对焦安排。 |
| 看纹理、微小机械过程、液滴或材料响应 | 微距把细小变化变成主要过程 | 明确放大的是哪里、运动沿哪个方向、哪一层清楚；浅清晰范围不能把关键过程留在焦外。 |

镜头感觉与机位距离一起选择：贴近主体并用广角容纳环境，可强化前后大小差异与穿越体感，但要检查靠近镜头的脸、手或产品是否符合造型要求；退远并用较长焦距保持主体大小，可弱化前后大小差异、让背景显得更贴近，但会改变空间动势与可见范围。同机位只变焦主要改变取景，不凭焦距数字宣称透视已经改变。自然观察、浅景深或微距都须落到本片需要的距离、清晰对象与背景关系，不套固定焦段配方。

<a id="viewpoint"></a>

## 视角与空间比例

从观众与事件的空间关系选择机位与构图：身处人物之间、贴近一个动作，或从上方看清整体排列，可以让同一事件获得不同的观看价值。仰拍、俯拍的情绪含义取决于人物处境、比例与环境，不固定对应强大或弱小。

机位高度与朝向决定看见哪些表面；机位距离影响前后对象的相对大小，广角便于贴近前景时仍容纳背景。框景可用近处身体、物件或空间边缘组织远处主体，遮挡与清晰范围须容纳关键关系。俯拍有利于显露队形、边界与路径，也可能削弱面部表演；根据观看重点取舍，不能只靠改变角度名称得到预期效果。

表现恢宏环境时，区分单个主体的体量与整个世界的规模。按场景需要，用可辨尺寸的参照、建筑或地形的延伸、前后遮挡和大气层次建立尺度，不仅依赖主体占满画面。展开镜头时说明哪些层次被显露，并检查展开后主体是否仍有预期体量；不把拉远自动等同于恢宏。

例如，前景小船保持可辨的船体结构，远处巨兽的脚落在同一水面，身体向上延伸并没入云层；小船经过脚边时，水面关系和相对运动继续显出体量。

构图的变化可沿用[遮挡揭示](staging-and-reveal.md#occlusion-reveal)，或用[前景掠过](staging-and-reveal.md#foreground-pass)组织纵深与运动层次。[垂直俯拍旋转](#overhead-roll)让画面围绕中心转动；绕主体移动则改变观察位置与遮挡关系，按所需变化选择。

```text
摄影机位于〈相对人物或场景参照物的高度、方位与距离〉，朝〈观察方向〉取〈景别〉。〈本段需要看见的人物、活动与环境〉按〈画面位置、占比及空间关系〉组织，使〈关键动作或关系〉清楚可见。
```

<a id="trunk-shot"></a>

## 后备箱内部仰拍／昆汀式后备箱视角

将观察位置放在汽车后备箱内部，朝开口外向上拍。箱口、车身边缘或开启的箱盖在近处形成框景，人物位于箱外，俯身或低头看向箱内；这种内外位置关系让观众仿佛处在被查看的空间中，可用于亮相、检查物件、对话或悬念。它首先是一种机位安排，固定摄影机也能成立。

明确箱盖在起幅时已经打开，还是随人物动作开启；需要开盖揭示时，交代遮挡怎样移开以及人物何时可见。按面部与手部任务选择广角范围、俯身距离和畸变程度，让箱口边缘、人物与外部环境共同建立空间。人物要取放物件时，交代物件在箱内的位置、手的路径与动作结果；若要合盖，再安排遮挡结束与声音。

```text
摄影机固定在〈汽车后备箱内部的具体位置〉，朝箱口外向上仰拍，〈箱盖起始状态〉。近处〈箱口与车身边缘〉形成框景，使用〈广角程度与所需畸变〉，箱外可见〈天空或环境〉。〈人物〉站在箱口外，〈俯身、低头或其他具体动作〉，视线落向〈箱内对象或镜头附近〉，完成〈表情、对白或取放任务〉。〈面部与关键手部〉保持可读，结束于〈人物、物件与箱盖状态〉。
```

参考：[用户提供的运镜示范](https://www.douyin.com/video/7703871643310918946)，约14—19秒的画面与字幕；保留箱内仰拍、箱口框景与人物俯视关系，衣装、墨镜、天气和强逆光按本片另选。上方为适配写法，未在本项目生成验证。

<a id="environment-tour"></a>

## 场面展开与环境游览

场面的空间规模、内部活动或环境本身承担吸引力时，结合人物行动与声音，让镜头显露值得观看的空间关系。单镜头可在原地转向、俯仰，也可移动中观察；按观看需要选择方向、幅度、速度与停顿，显露相邻区域、内部活动及其空间关系，保留所需的体量与辨识度。采用位移时，再利用遮挡变化和前后视差展开空间。人物留框、出画或重新进入，按各镜的观看作用选择。多个镜头选择有不同观看价值的位置，分别显露整体格局、内部活动与层次或身处其中的体验，避免只换角度重复同一信息。不强求固定顺序，也不要求每镜扩大景别；场面已经充分可看时，可以用小幅运动留出观看时间。

写法沿用[运镜与取景](#camera-move)，明确途中显露的区域、活动与空间关系。

<a id="overhead-roll"></a>

## 垂直俯拍旋转

```text
摄影机位于〈场面〉正上方，垂直向下，〈空间中心〉处于画面中心，周围〈人物、物件或边界的排列〉可辨。机位与向下的朝向保持不变，摄影机绕光轴按〈方向、速度与幅度〉旋转，画面中的排列围绕中心转动；〈主体动作〉持续，落在〈结束构图与动作状态〉。
```

<a id="motion"></a>

## 相机相对运动

领拍、跟拍能显露前路还是身后信息，取决于机位位置、镜头朝向与构图。机位相对身体固定时，身体位置近似稳定，背景与地平线的运动可产生失衡感。相机与主体同步移动若显得原地踏步，可用前景掠过、相对距离变化或短暂落后来显出速度。

原地转向改变观看方向，显露不同区域；位移改变观察位置，可产生视差并改变遮挡关系；原地变焦改变取景范围与放大倍率；拉焦改变清晰对象。按需要改变的内容选择或组合。

[滑动变焦](#dolly-zoom)适合让主体相对稳定、周围空间的感受发生改变。背景保留可辨认的纵深层次，触发时机、变化幅度与人物反应共同决定它的作用。

[透视错位与揭穿](#forced-perspective)用初始视点下的近远对齐制造错觉，再以视差揭出实际间距。前后对象的清晰范围、初始投影与揭示路径共同决定读法；生成是否保持真实尺寸和连续空间仍需看成片。

同一揭示可以组合后退、转向与升高；时间冻结时保留机位运动，则由空间视差提供观看过程。

## 原地变焦

```text
机位保持〈位置与朝向〉，〈延长焦距缩小取景范围／缩短焦距扩大取景范围〉，主体和背景在画面中同步〈放大／缩小〉，停在〈最终构图〉；前后景保持原机位的透视关系。
```

<a id="rack-focus"></a>

## 拉焦

```text
〈已选构图与摄影机状态〉。初始焦点落在〈对象A〉；到〈动作或声音节点〉，焦点以〈速度〉交给〈对象B〉，使〈B的反应或信息〉变清，A变为〈所需清晰程度〉，停在〈最终关注对象〉。
```

## 身体相对固定

```text
摄影机位于〈主体身体的相对位置与朝向〉，随〈主体动作〉同步运动，〈躯干部位〉在画幅中的位置与大小近似稳定。〈背景与地平线的运动〉以及〈前景掠过或空间锚点〉显出〈目标体感〉，结束于〈动作与画面落点〉。
```

<a id="pov-continuous"></a>

## 第一视角、持机与连续路径

先确定观众借谁的位置观看：人物眼睛附近、胸前或头部挂载、手持自拍、物件上的相机，还是自由飞行的FPV。几种观看位置产生不同运动和可见身体范围，不把所有“第一视角”都写成无人机飞行。

需要手部操作时，明确哪只手持什么、支撑相机在哪里、操作对象与行进方向。如果双手都在攀爬，画面仍是手持手机，就存在输入冲突；可以采用已符合意图的挂载位置或另一拍摄者，不用删掉攀爬动作解决。自拍还要区分手机所拍画面与第三人称看见人物拿手机的画面。

连续镜头由可通行路径串起观看变化：从何处开始，绕过哪个锚点，穿过什么开口，最终面向哪里。先选择观众要经历的动作、发现或速度，再安排路径；“无切镜”不能把本应发生的接触和转身省成瞬移。摄影者停步、侧身让路、俯身或回头会改变画面，选择对本片有用的变化，不随机添加手持抖动。

开场可以已经在行动中，仍要留下理解身体位置、当前任务和下一步方向的线索。连续路径里可有多个动作、转向与焦点交接；同一动作链不受“每镜只能一动作”限制。需要强幅度运动时，用明确路径和观看关系落实，不能无依据改为静止观察。

原创示例：头部视角进入狭窄修表台，左手扶住台灯底座，右手把一枚铜齿轮放进钟芯；头部向侧边移开避让摆锤，再抬头顺着正在转动的齿轮列看向墙上大钟。手的分工、头部位移和声音变化连成同一路径，不是三个独立视角的蒙太奇。示例未生成。

本节参考[LearnPrompt第一视角模板](https://github.com/LearnPrompt/awesome-seedance/blob/4889d7b0baef89ba1356e2f9e3225e50439bb276/docs/templates/zh/pov-continuous-take.md)的挂载位置、手部任务与空间路径；未采用固定FOV、统一手机质感、固定动作数或禁电影化表达。动作接触细节沿用[动作与空间](action-and-staging.md#continuity)。

```text

```

### 背景逼近

```text
〈主体与可辨认的背景层次〉。在〈节点〉，摄影机后移并延长焦距，使主体画幅占比与位置基本稳定，跟随对焦保持主体清晰。背景相对主体逐渐放大、显得逼近，纵深压缩；场景物体形状连贯。〈主体反应与结束构图〉。
```

## 透视错位与揭穿

```text
〈近处对象〉与〈远处对象〉在初始视点下按〈轮廓、位置与画幅比例〉对齐，形成〈大小或接触错觉〉，两者清晰可辨。到〈节点〉，〈摄影机或主体〉沿〈路径〉移动，投影对齐被打破，借〈可见间距、遮挡或地面关系〉揭出实际空间。过程中两者保持真实尺寸，〈动作与结束构图〉。
```

### 示例

```text
近处的拇指与食指分居远处行人的头顶和脚底，在画面上仿佛捏住一个小人。摄影机向右侧移，手指和行人逐渐错开，露出手臂与延伸到行人脚下的地面；行人仍在远处正常走路，手指只捏着面前的空气。
```
