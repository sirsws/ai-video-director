# 画面效果

<a id="time"></a>

## 时间速度与方向

需要调整动作节奏时选[变速](#speed-ramp)；需要探索停住的瞬间时选[空间冻结](#freeze-space)；事件仍极慢推进、观察视角相对活跃时用[子弹时间式拍法](#bullet-time)。直接定格画面不再呈现场景内的新视点，仍可按需要对静帧作后期推拉。

冻结的传播范围见[逐区冻结](#propagating-freeze)，不同对象的时间方向见[局部逆向](#local-reverse)。声音可随事件速度变化，也可保留正常的呼吸、对白或音乐，形成主观时间与环境时间的对照。

<a id="timelapse"></a>

时间压缩可用固定延时或移动延时：固定机位保留可辨地标，让云影、人流或光照变化证明时间经过；移动延时还需给出摄影路径、沿途持续可辨的地标及取景关系，让时间加速与空间推进同时成立，不把摄影位移写成建筑变形。明确哪些对象共同加速，哪些有意保留另一时间层，日夜与光源变化如何连续；普通人物忽然正常速、机位跳位或天气无因重置不能靠“延时”标签解释。固定延时的场景变体见[城市延时变体](../examples.md#environment-example)。

## 变速

```text
〈动作与构图〉以〈起始速度〉进行，到〈动作节点〉按〈过渡节奏〉转为〈目标速度〉，突出〈关键变化〉。其后〈保持该速度或再次变速〉，动作接续至〈结果〉，〈声音响应〉。
```

## 空间冻结

```text
〈开场状态与冻结时机〉。〈冻结范围内的对象〉保持在〈姿态、位置或悬停状态〉。摄影机〈保持观察位置／沿路径与速度改变观察角度，显露对象的侧面及遮挡关系〉，对象在场景中的位置保持。〈按需要补充仍活动的对象及动作〉。结尾〈保持冻结、恢复动作或转入下一状态〉，〈声音设计〉。
```

## 子弹时间式极慢动作

```text
〈动作与环境运动〉以极慢速度持续推进，可见〈连续的微小位移〉。摄影机以相对更快的节奏沿〈路径〉观察，揭出〈空间关系或关键细节〉；到〈节点〉进入〈后续速度与动作结果〉，〈声音响应〉。
```

<a id="propagating-freeze"></a>

## 逐区冻结

```text
〈冻结前的场景状态〉。到〈节点〉，冻结从〈起点〉沿〈空间顺序〉推进；各对象在冻结抵达时保持〈当时的姿态与位置〉，形成〈已冻结区域与其余区域的关系〉。〈镜头观察、声音与结束状态〉。
```

### 示例：带传播效果的冻结

```text
〈场景与起始构图〉，〈人物〉正在〈动作或逐字台词〉，镜头〈已选定的运动与落点〉。周围〈人群或物体〉保持正常运动，以〈可辨认的进行中动作〉建立时间流动的基线。
人物〈触发动作〉的瞬间，〈传播效果〉从〈起点〉向〈方向或范围〉扩散。效果扫过〈第一类对象〉，〈其正在发生的动作〉立即定格；继续扫过〈第二类对象〉，〈另一种可见运动〉也停在半途。冻结发生在效果经过各对象时，已冻结的姿势与空间位置保持不变。
传播效果消散后，〈场景的声音变化或寂静〉。〈不受冻结影响的主体或细节〉仍在〈持续动作〉，与周围静止的〈视觉锚点〉形成对照，最后停在〈画面落点〉。
```

<a id="multiple-images"></a>

## 多重影像、残影与虚影分身

用于万千虚影、动作拖影、多重姿态叠加或同源分身变幻；主体可以是人物、动物、物体等，不依赖武器或出刀。舞蹈、走位、手势、飞行及局部形态变化都可借用这种影像组织。

先决定影像关系：时间残影留下同一主体的相邻动作阶段；虚影分身则需说明与本体同步、错拍还是独立行动。时间残影可写成新影出现时旧影尚未消散，相邻轮廓细密错开，叠成连续影流；独立分身另按[群体表演](performance.md#group-performance)安排各自行动，不把两种关系混写。

让影群随本片过程变化：可以拖长、回卷、环绕、上下错叠，或从整体轮廓转为局部重影。主体也可相对稳定，由局部动作或影像位置的变化驱动。按观看回报选择展开、聚合、消散或持续存在，归一并非必选结尾。主次、虚实与材质服从本片风格；写实重影可保留部分身体或物体细节，外围由速度拖虚。需要高密度时可给轮廓层次目标，不把它自动解释为同等数量的独立角色，也不固定数量、覆盖距离或合影次数。

摄影要能容纳本片承诺的影群，并读到形态变化；取近景时明确留下哪个局部。镜头运动与影像自身的重排分别写清，避免只增加一列跟随主体的相同轮廓，却没有所需的疏密与形态变化。

```text
〈主体〉的〈整体或局部〉形成密集同源重影，相邻〈姿态或形态〉细微错开，新影出现时旧影尚未消散。随〈本片的动作或变化〉，影群从〈初始组织〉连续变为〈后续组织〉，〈主次与虚实〉保持可读。镜头〈观察位置与变化〉显露这一过程，最后〈继续、聚合、消散或留下分身〉。
```

这里的人物重影方法包含实际应用后的效果取舍；其他主体与场景属于适配方向，仍须看各片实际结果。“多重曝光”描述视觉外观，不据成片断言模型内部算法。

<a id="material-transition"></a>

## 受控材质转换

```text
〈对象与初始材质〉处于〈姿态或动作〉。到〈触发节点〉，〈变化区域〉以〈同时转变或从起点推进的方式与节奏〉变为〈目标材质〉，可见〈纹理、透明度、反射或形变响应的具体变化〉；〈指定保留的轮廓、部件、位置或动作〉连续保持。镜头〈观察方式〉显出〈变化边界或前后差别〉，结束于〈目标状态与后续动作〉。
```

### 示例

```text
手指轻触白色陶瓷杯壁，触点附近先变成透明玻璃，透明区域沿杯壁向两侧展开，逐渐露出杯内的茶。杯形、杯柄位置和茶水液面保持，原先柔和的白色反光随转换变成玻璃边缘的亮线；手指最后停在已经透明的杯壁上。
```

## 部件重组

```text
〈原对象与结构〉处于〈起始状态〉。到〈触发节点〉，〈原部件〉沿〈可见路径与先后关系〉展开、折叠或拆合，分别形成〈新部件及其功能〉；〈保留的辨识特征或持续动作〉贯穿变化。〈机位与光线〉使关键连接和结构变化可辨，最后〈新结构完成，按需接首次动作〉，〈声音响应〉。
```

### 示例

```text
雨伞的伞骨逐根脱开，绕中心轴折成鸟翼；伞柄弯成颈部，伞布收束成羽片。原来的红色伞尖一直可辨，最后成为鸟喙，第一次振翅带落残留雨珠。
```

<a id="effect-interaction"></a>

## 特效与实景联动

先确定效果从哪里产生、由什么材料或形态构成、沿什么路径发展，以及结束时消散、停留还是留下改变。重力、风、碰撞与遮挡按本片世界的规则参与过程；主观图形、持续雨雪或循环光效不必为了填步骤而强制落地或消失。

| 效果需要解决的问题 | 可见依据 |
| --- | --- |
| 烟雾或蒸汽有方向，却像贴在画面上的覆盖层 | 交代喷口或释放处、浓淡与扩散方向；经过前后物体时发生遮挡，光束只在相应区域显出。上升或下沉由所选物质和情境决定，不把所有白雾都写成下沉。 |
| 水滴、液体或碎屑缺少重量与接触 | 让来源、落点与表面响应相接，如液滴合并后滑落、撞到杯沿分开，或碎屑碰桌后弹起再停；不凭震动和巨响代替实际接触。 |
| 光、能量或粒子与主体脱节 | 明确附着点、传播范围与路径，选择会被照亮、反射或推开的对象；效果变弱或离开时，对应响应随之改变。 |
| 效果结束后场景无故复原 | 明确留下的湿面、灰烬、缺口、余光或变形；后续镜头沿用已形成的状态，确需恢复时给出恢复过程。 |

按当前回报选择需要读清的响应，不为真实感堆满所有物理项。脸、手、产品标识等必须可辨时，安排效果经过的位置、密度与时机；用户要求主体本身发生变化时，使用[结构变化与状态连续性](#structural-change)，不能用“保护身份”取消该变化。多种效果可以共同组成一个过程，分别说明它们的因果或主次，避免相互遮掉证据。

```text
〈效果〉从〈来源〉以〈材质、密度或形态〉沿〈路径与推进方式〉发展，通过〈本镜起作用的遮挡、光影、接触或物体响应〉与〈场景对象〉发生可见联系。随〈过程节点〉，〈对应关系的变化〉持续至〈停止、延续、消散或残留状态〉，〈人物反应与声音〉。
```

### 示例

```text
指尖亮起的小光团从杯柄后绕过，先被杯身挡住，再在金属勺背映出一点亮斑；它擦过桌面带起几粒灰尘，最后缩进杯底，亮斑一同消失。
```

<a id="structural-change"></a>

## 结构变化与状态连续性

当全局描述或参考图限定了初始形态，折叠、拆装、损伤等变化后仍沿用初态要求，可能与当前状态冲突。

稳定身份与阶段状态分开写：初始形态要求只用于变化前；变化发生时写清对象、变化及结果，后续再次出现或切镜时，明确是同一主体并延续当前形态与相应动作，不只裸用旧变量。必要时将后态单独命名，说明它是原主体变化后的状态；换名本身不保证连续性。

需要更强控制时，可按当前输入能力提供后态参考，并检查其是否污染开场；实际稳定性仍待成片验证。变化恰在主体最后一次出现时可以自然收束，但不为规避风险自动安排退场、毁灭或删改用户锁定的高潮。
