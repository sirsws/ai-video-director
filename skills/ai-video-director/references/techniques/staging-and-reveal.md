# 调度与揭示

按[方法调用与复用规则](../creative.md#method-use)读取本片相关小节，已有充分决定直接沿用；其余专项小节按本片需要的揭示、群像或分屏等任务选读。

<a id="attention"></a>

## 焦点与调度

注意力交接可通过[拉焦](camera-foundations.md#rack-focus)改变清晰对象，或通过[遮挡揭示](#occlusion-reveal)改变实际可见范围。固定机位也可以让人物进入、让开或占住前景。若笑点靠背景事件与前景反应同时成立，两者的可读性比单独突出一方更有用。

[反应先行](#reaction-first)让观众先猜原因，再由揭示重新理解反应；观众先知道原因，则可以期待人物何时察觉。按这段想制造的好奇、悬念或笑点选择信息顺序。

<a id="hero-orbit"></a>

## 英雄式环绕

围绕一个人建立气势时，可用低机位环绕：通过低机位、主体构图与背景相对掠动突出人物，并让起身、转身或抬眼等关键表演与运动节点接应。环绕方向、速度、弧度和焦段按画面选择，不把逆时针、长焦或完整一圈当作固定配方；同样的绕行也可服务不安或受困感。

```text
〈人物、姿态与起始构图〉。摄影机从〈低机位方位〉沿〈相对人物的弧线路径与速度〉绕行，保持〈主体在画幅中的位置与大小关系〉，背景〈可辨认的空间层次〉相对掠过。人物在〈运动节点〉从〈起始姿态〉完成〈关键动作〉；取景容纳〈决定动作读法的身体或道具〉，镜头落在〈结束姿态与构图〉，以〈停顿或后续动作〉收束。
```

### 示例：起身与镜头升起同步

```text
低机位从侧前方取半蹲男子的中景，画面包含撑在膝上的手。男子撑膝起身，摄影机同时沿弧线绕向正前方并随他升起，脸部始终留在画面上部，身后的石柱逐根横移。他站直时手从膝上离开、垂至身侧，抬眼望向前方；镜头停在微仰的半身构图，停留在站稳后的姿态。
```

<a id="ensemble-entrance"></a>

## 多人物连续亮相

需要逐人认识角色并在结尾建立群体关系时，可用连续亮相。先决定落幅中谁居核心、谁与谁并肩或对峙，再反推人物站位、出现顺序及摄影机路径；用拉焦、前景进入或遮挡移开交接注意力。下一人物在交接前已有明确空间位置，避免只靠突然出现维持连续感。

亮相的魅力依靠动作时，将人物从什么姿态开始、怎样完成动作、停在哪里与镜头对应；景别须容纳起作用的手、身体或道具，不能让动作发生在特写画外。气势可以来自克制动作后的停顿，不必增加武打；风吹衣袍和背景移动也可支持气势与情绪，按它们对本片亮相价值的作用选择。结尾留出读懂姿态和人物关系的时间，不把所有人平均分秒或统一成同一种演法。

```text
〈同一场景中人物的前后层次与最终关系〉。起幅关注〈人物A〉，完成〈A的亮相动作〉。随着〈摄影机路径或人物调度〉，通过〈焦点交接／前景进入／遮挡移开〉让原本位于〈明确位置〉的〈人物B〉获得关注，并完成〈有区别的动作及结束姿态〉。按本片需要继续交接，已出镜人物保持〈空间位置或可追踪的移动〉。最后通过〈人物调度、切镜、运镜或原有构图〉显露众人的〈站位、视线与关系〉，留出读清〈核心人物、关键道具与群像〉的落幅。
```

<a id="split-screen"></a>

## 分屏与多联画

先确定各屏怎样共同产生观看价值：并行事件、视角或状态对照、声画呼应，或跨边界互动。情绪与声音也能连接各屏，不必安排人物跨屏接动作。根据观看重点分配各格大小与动静，让关键变化有清楚的注意力落点；景别和动作范围按每格实际形状选择，不只看总画幅。

对比型分屏可将同一组动作按各自情境所需的不同顺序展开，让各屏形成持续可比较的过程；同步呈现不要求逐拍同动作，各屏分别保持动作因果与物件状态的连续。

布局、各屏角色归属与时间线、格内运镜和切镜分别设计，不因同场同步就要求各屏共同换镜。同一人物可按设计出现在多个视角，明确各屏持续跟随谁及何时换主体；约束错误归属，不笼统禁止同人多屏。声音明确来自哪一屏、贯穿哪些画面及主次关系。跨框接触或传递时，交代边界两侧的接触位置、方向、尺度与动作承接。需要参考输入时，在当前方案的参考图清单中写明面板布局、各格出现时段和必须保留的跨框关系。

<a id="media-boundary"></a>

### 银幕、镜面与画框越界

人物穿越银幕、镜面或画框时，先定两侧分别是什么空间、是否为同一人物，以及边界在接触前后怎样约束行动；保留越界当下的接触与身份接续。例如镜中手抓住现实手腕，要说明是同一人的映像获得独立行动，还是另一人物越过镜面，不能因越界含混地多出一个人。若首次穿出已完成回报，可在此结束；普通分屏不必增加越界事件。

<a id="fixed-parallel-panels"></a>

### 写法：固定并行分屏

用于多个面板在同一时段并行持续的最终画面，不用于表达先后顺序的分镜图。固定布局不等于各格都必须一镜到底；格内切镜与跨屏关系按上述关系设计。面板边界需要变化或发生跨框互动时，按具体导演方案改写，不套用固定结构。

```text
〈全片／指定段落〉采用〈上下／左右／其他布局〉〈面板数量〉联画。〈有分屏锚定图时：画布继承{分屏锚定图}；〉〈面板数量、比例与边界关系〉从〈起点〉到〈终点〉保持。

{面板A}=〈位置；主体；场景；基准构图〉
{面板B}=〈位置；主体；场景；基准构图〉
〈按实际面板数量增减〉

〈起点〉—〈终点〉：{面板A}持续〈动作及变化〉；同时，{面板B}持续〈动作及变化〉。各面板保持自己的主体、空间与动作连续。

〈按需〉{面板A}在〈节点〉格内切至〈景别／视角〉；{面板B}同时〈保持连续镜头／发生对应变化〉。切镜仅作用于指定面板，分屏布局保持。

声音：〈声源与所属面板／画外声音〉贯穿〈画面范围〉，〈其他声部的主次关系〉；在〈关键节点〉与〈画面变化〉形成〈同步／提前／延后／反差〉。

〈需要共同收束时〉到〈收束节点〉，{面板A}完成〈可见结束动作〉，{面板B}完成〈可见结束动作〉；只停留到观众看清〈最终关系〉。
```

<a id="occlusion-reveal"></a>

## 遮挡揭示

```text
〈起始构图与遮挡关系〉。在〈触发时机〉，〈摄影机或主体〉沿〈路径与速度〉移动，使〈遮挡边缘〉相对〈待揭示区域〉移开，按〈显露过程〉露出〈人物、事件或关系〉，落在〈结束构图〉。
```

<a id="foreground-entry"></a>

## 前景闯入

这里通过主体进入近前景改变观看重点；参考片所称的“斯皮尔伯格闯入式”若实际是摄影机缓慢向人物推进，按[情绪推近](camera-foundations.md#emotional-push-in)处理。

```text
〈背景事件与构图〉正在持续。到〈节点〉，〈闯入主体〉从〈画面边缘〉进入近前景，占据〈画幅范围〉，通过〈遮挡、焦点交接或动作〉接管注意力，形成〈新的主体与背景关系〉，以〈关键反应或动作〉收束。
```

### 示例：近前景互动

```text
固定机位，〈背景事件与初始构图〉，〈光线与环境气氛〉。就在〈背景事件的关键时刻〉，〈闯入主体〉突然从〈画面边缘〉进入极近前景，占据〈画幅范围〉，遮挡〈原关注对象〉。焦点由背景转到闯入主体，〈原背景的清晰度与可见程度〉。由于〈主体与镜头的距离及透视效果〉，〈局部形态〉显得夸张。它先〈察看镜头的动作〉，随后〈进一步互动〉，最后〈最贴近镜头的动作与落点〉。〈原有气氛〉被打断，转为〈目标感受〉。
```

<a id="foreground-pass"></a>

### 变体：前景掠过

```text
〈主体动作与构图〉持续，〈前景物件〉沿〈路径〉从镜头近处掠过，短暂遮住〈画面区域〉后移出。〈中后景的主体或环境〉保持〈可辨状态或不同的运动节奏〉，形成前后层次；〈关键动作或关系〉在〈间隙或落幅〉清楚可见。
```

<a id="reaction-first"></a>

## 反应先行，延迟揭示

```text
先看〈人物与构图〉，引发反应的〈对象或事件〉暂在画外或被遮挡。人物〈可见反应及其变化〉；到〈揭示节点〉，通过〈切镜、运镜或人物调度〉显露〈原因及空间关系〉，由〈后续动作或反应〉完成这一拍。
```

### 示例

```text
走廊中景，两个人看向画外，同时侧身贴墙让路。镜头后退带出正从两人之间经过的主角：他双手端着一碗满到边沿的热汤，嘴角强撑着笑，步子越迈越小。
```
