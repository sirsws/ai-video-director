# 参考图判读与制作

承接[参考输入方案](production-and-delivery.md#reference-plan)，依次决定图片要补充什么、怎样表达与组织，再制作、校准和交付。沿用作品已有授权，涉及用户锁定要求或范围变化时按主流程处理。

## 图片用途与取舍

按本片需要传达的具体视觉选择判断图片的作用。

- 已有角色设定、身份输入与文字足以表达关键外观和关系，图片没有具体增量时，可以不用图。
- 图片可提供具体造型、材质、布局、连接关系或选定的美术设计。项目提供图库时先定向查适用素材，缺少再设计；不为凑图数出图，也不假定存在私人资产目录。
- 比较收益与干扰：图片是否提前带入后态、锁住姿态或与拍法冲突。可改用前态、独立设定或针对关系的画面，不必先生成多套做比较。

| 本片需要补充的信息 | 可采用的表达 |
| --- | --- |
| 人物、衣装、道具或场景的外观与结构 | [设定图](#basic-assets)。 |
| 具体构图、人物与环境的关系、某一时刻的状态 | [具体画面参考](#anchor-image)；需要表达先后状态时，再组织成[分镜](#storyboard)。 |

这些用途可以配合，同一张图也可同时提供外观、结构与关系依据。空间、接触或连接关系可由设定图、关系示意或具体画面承担，按现有输入能否清楚表达这些关系决定是否补图。

在对话中简记选图理由：图片具体提供什么，或现有输入为何足够。静态图与预演各提供自己的依据，不能单凭“不能证明动态”排除图片。暂不出图而方案仍需图片时，保留图的设计、完整制图词及视频正文引用。

## 设定图

设定图说明人物、衣装、道具或场景的具体外观与结构，按本片需要选择以下内容：

- **普通 AI 人物设定。** 按本片的人物魅力、角色辨识或跨镜一致性需要，可单独设计 AI 人物，用干净背景呈现面孔、发型、体型、衣装和气质，保留完整脸部；视角及必要的表情展示按本片需要选择。
- <a id="costume"></a><a id="无头纯服装设定图"></a>**独立衣装／数字分身造型。** 身份另有来源、图片只需提供衣装时，可用干净背景呈现同一套衣服的正、侧、背及衣物立体形态，保持剪裁、颜色、材质、配饰和装备一致，不混入不需要的人脸、皮肤或人台部件。需表达体型、身体比例或裸露部位时，使用保留身体的造型图；身份冲突及必要处理按[头区规则](#head-identity)判断。

  视频正文将衣装、装备绑定到各自角色，视图排版不带入视频。发型、冠饰确需参考时，以无头模的独立造型部件表达，不为展示配饰补画脸。若纯服装图误生成头模、人脸或皮肤，先修正后使用。
- **其他主体／道具设定。** 用干净背景与中性状态表达整体形态、材质和必要结构。
- **场景设定。** 提供环境、布局、材质、色彩、光线和场面规模，可含军团、人群、群演、动物群及载具编队。已有独立设定的唯一核心主体默认不重复放入场景图；现有组合不足以表达决定成败的空间关系时，再补相应的关系示意或具体画面。

多个核心主体在远景或快速动作中仍需辨认时，用主色块、明暗、轮廓、材质或装备提供区分。承担尺度参照的现实物件保持可信尺寸与可辨结构。图片提供静态依据，动作、摄影及状态变化由视频正文继续组织。

## 具体画面参考

用具体画面共同表达人物造型、构图、空间关系及某一时刻的状态。它可以与设定图配合，也可以独立承担本片需要的参考作用。

图片承担具体时刻的状态参考时，说明图示对应开头、途中还是结束；图示为途中或结束目标时，正文写清怎样到达及如何继续，不把摆到图中姿势当作整段表演。含数字分身的人物画面按[头区规则](#head-identity)处理。

需要突出关系时，明确主体、空间、物件或关键效果间的距离、朝向、接触、遮挡和连接，核对其中可见的身份、造型、场景与其他输入相容。有特定适用时段或目标状态时再注明；这些关系可与其他设定或构图共用同一张素材。

<a id="storyboard"></a>

### 分镜图

分镜用少量关键画面表达先后状态、动作与构图，格数不决定镜头数。在参考图项注明阅读顺序，以及相邻状态是连续可达还是通过切镜连接。

- 各格依据同一套已定设计制作，保留必要外观和空间细节，不把整段视频逐拍细画。
- 背景连续性重要时，先确定场景布局与共同地标，再改变观察位置、人物和动作；场景细节可由独立设定图承担，避免每格重新生成不同房间或地形。
- 关键关系须在画面中成立，格内文字只作辅助；已有海报或拼贴按实际用途判读，不直接当作连续分镜。

## 图片的组织与使用

选定的设定图或具体画面可以分别交付，也可以合成一张图版，沿用本次已定输入方案。逐张、逐格用编号或明确位置说明内容和用途；图版各格可以承担不同参考作用。三视图描述同一对象，不表示多个人或连续动作；独立构图按各自用途引用，有先后关系的画面按分镜说明阅读顺序和承接。

各格可独立制作、修订后合成；同一分身的多个状态可这样组织，避免无必要地分散上传。已有可用素材在不损害组合关系的前提下原样复用，只补缺失部分。图数、图版格数与视频镜头数分别确定，图版排版不自动要求成片分屏。

已有多格素材的用途不明，且不同解释会改变人物、动作或布局时，先补清用途。实际上传数量、格式和输入控制以当前入口为准。使用时明确以下关系：

- **普通参考。** 图片按声明的用途提供外观、构图或状态依据，不因只有一张就自动成为首帧。
- <a id="keyframes"></a><a id="独立关键帧"></a>**首帧与其他专门状态输入。** 入口支持专门首帧、起止或中间状态输入时，按已确认清单逐张绑定。首帧须满足开场；相邻状态写清怎样连续到达或为何切换，保留必要路径、时间与对象追踪。普通参考模式中的文字声明不保证精确对齐。入口不支持时说明控制边界，按可用方式调整拍法与正文；改变用户指定方式时沿用主流程。

<a id="split-screen-reference"></a>
<a id="有意分屏或多联画"></a>

图片用于表达已定的成片分屏布局时，明确最终画面中的面板数量、比例、边界、各格内容及必须保留的跨框关系。可用对应最终画布的合成布局图，或独立面板图配合正文说明布局。各格的稳定指认、出现／持续／退出、全程并行及格内运镜、切镜，按[分屏方案](techniques/staging-and-reveal.md#split-screen)和[正文编译](prompt-compiler.md#视频提示词编译)落实。作为首帧时逐格核对开场，其他用途按实际出现时段核对，避免把先后状态误作同时发生。

## 制作与处理

参考图的生成入口与执行范围按[主 Skill 的使用条件](../SKILL.md#使用条件)执行；落实以下共用要求：

- **继承已定设计。** 制图词承接本片的审美参照、造型与拍法；风格转换明确对象、范围与层次，光色和材质按[光线、材质与影像质感](techniques/look-and-effects.md)的相关部分落实。画面文字承担识别或操作信息时，按最终观看尺寸安排字号、对比和信息量，保留用户指定的文字与识别元素。
- **核对图片的全部可见影响。** 人物、场景、机位、姿态、光线、材质和文字都可能进入生成，声明用途不能隔离其余内容。后态或高潮图可能提前泄露结果；影响关键识别、因果、动作衔接或观看效果时，修图、换图或调整拍法，不能靠“忽略”压掉冲突。未锁定且不影响关键表达的陈设和构图差异可以接受。
- **按用途选画幅与范围。** 普通参考图不默认沿用视频比例。场景图展示必要区域、连接和活动空间，精确布局保留关键细节，大场面或连续运动留足取景余地；场景视图不等于视频机位。首帧或锁定画布的输入按对应模式核对。
- **复用与编辑。** 已认可资产适用时直接复用；裁切、转格式、合成和写入 Alpha 用本地工具，保留原图及必要视角、设定细节。生成式修改先确认变化幅度与保留项相容，只处理授权目标，按修改目标及脸部、饰品、纹理等保留项验收；冲突时不放松锁定要求。移动或删除对象时同时检查阴影、反射和接触痕迹。
- **保持输入分工。** 核对各图是否争夺同一身份、空间或时间状态；需要调整时同步相关设计、素材与正文。用户锁定的图数、用途和交付范围沿用原要求。折叠、拆装、损伤等变化按[结构变化与状态连续性](techniques/spacetime-effects.md#structural-change)核对前后状态。

### 数字分身与头区处理

身份沿用本次用户指定的人物来源与实际绑定方式，不默认用户本人或特定账号。普通 AI 人物需要保留参考图中的脸时，保持完整人物设定；采用数字分身时，区分身份来源和衣装、身体、姿态参考，核对各输入是否争夺面孔或造型。

- 是否需要移除头部、是否接受透明图，由当前入口和项目约定确定；不把某人的抠头习惯作为普遍要求。使用即梦时可读[入口适配](platforms/jimeng-seedance.md)。
- 明确采用完整头区透明方案时，才按[Alpha 操作](reference-image-alpha.md)处理并保留原图。多图逐图、逐格核对覆盖与保留范围；仅供预览的原图和正式上传图区分。
- 去除头区后，本片仍需要的发型、头部朝向、表情或冠饰须由其余实际输入或正文提供；透明操作本身不证明身份绑定成功。

## 校准与验收

对照实际图片核对其参考用途、作品方案与视频正文；需要修订时更新受影响内容：

- **画面与设定：** 人物、衣装、道具、文字和画布符合本片要求；完整画面与场景看构图和整体观感，主体设定看造型、结构和材质，表达关系的图片看关键关系是否可读。
- **过程与空间：** 图片支持必要持物、接触、朝向、通路及运动空间；用过预演时对照其关键关系，允许不影响判断的美术与视角差异，不照搬灰模外观。
- **组合效果：** 多图合看廓形、光色、材质及主体与背景分离，不能只以各图单独好看通过。共同表达同一对象、场景或事件时，按下方[跨图一致性](#跨图一致性)要求检查。
- **证据范围：** 未出图只核对设计文字，实际验收只记录可见事实；静态图片不证明动态、口型、声音或生成稳定性。

### 出图后逐格校准

仅对按时间顺序展开的分镜执行。设定多视图、单张画面、关系图按各自用途核对；分屏按并行关系，独立关键帧按起止与过渡核对。

对照实际图片更新作品已有方案，每格用编号或明确位置对应以下内容：

| 项目 | 对应内容 |
| --- | --- |
| 时间与图片时刻 | 对应片段及图示是开始、途中还是结束，不默认每格都是片段首帧。 |
| 画面动作 | 片段的开始、行动与结束状态；怎样经过或到达图示状态，人物、道具归属怎样变化。 |
| 摄影与衔接 | 景别、机位、保持或移动，移动的起止与可见内容，前后段怎样衔接；不为填栏目新增运镜或切镜。 |
| 声音 | 音乐、人声、音效与动作、切镜的配合；跨段声音统一说明，变化处再补写。 |

### 跨图一致性

正式输入前，按图片共同承担的内容核对：

- **同一对象：** 身份、衣装与道具归属符合本片设定；不同造型或状态按各图已定用途区分。
- **同一场景：** 能以门窗、家具、主要光源等共同地标还原为一套空间；换机位后的左右、前后、距离与遮挡能解释。
- **连续过程：** 图片表达前后相接的过程时，再核对人物方向、镜轴、出入口和可通行路径，穿越、进出或接触能从前态到达后态；衣装、道具归属及动作前后态连续，变化有明确的换装、换景、时间跳跃或切镜依据。

关键矛盾未消除时先修图或换图，不能以“同一空间”等文字代替实际图片证据。校准结果同步到最终提示词，不另建重复文档、HTML 或长图交付，也不要求把声画说明排在图片上。

## 交付与异常处理

实际图目检通过后作为正式输入交付；未生成或未通过的在对话中说明。文件、完整制图词、图片组合、用途与上传顺序按[统一交付格式](production-and-delivery.md#完整交付-md-模板)提供；潜在影响及一致性判断在对话中简述。素材变化后按[变量与引用规则](prompt-compiler.md#视频提示词编译)同步正文。正式资产目录只放选定图片，失败稿与临时预览放系统临时目录，已有文件的删除沿用项目约定。

每张图初次生成后最多进行两轮有明确归因的修正；重复同路径失败时停止重试。生图或编辑长时间无返回、连接失败时，交付完整可粘贴的制图词、参考图、上传顺序和用途，供用户转网页继续。保留原提示词及约束，不因卡顿自行缩短或改写；用户要求原样对照时保持输入一致，区分工具异常、尚未生成与图片未通过验收，不擅自归因于长度或内容。

工具返回的图片用图片展示能力传递，文本只提取必要路径、状态、参数或错误信息；不输出图片编码或包含它的完整结果对象。
