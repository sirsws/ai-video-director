# 行动与空间调度

按[方法调用与复用规则](../creative.md#method-use)读取本片相关小节，已有充分决定直接沿用；武打、追逐、地形利用及速度感等专项按任务选读，动作承接与受力问题同样按需要定位。

<a id="action-scene"></a>

## 武打、攻防与追逐

武打、追逐承担主要观看过程时，围绕人物争取的结果组织关键交锋。一方的行动引出另一方的应对，距离、重心、主动权或退路的变化再影响后续选择。张力也可来自持续压迫或僵持的积累，不必逐招反转。

持续对抗中，分别判断行动是否需要转移、观众是否需要看见更大范围。人物留在原地，也可通过其他区域的行动及其影响展开战场；不以移动距离判断场面是否充分。

用户要求明确交锋数量或密度，或设计疑似只有跑位与特效而缺少实际交锋时，可分别核对双方发起的攻击及往返过程。激烈感还可由力度、速度、险境与反应形成，不单凭攻击次数判断；只统计具有明确目标的实际攻击，不把运镜和特效计为交锋。

涉及主体的不可逆结构变化时，按[结构变化与状态连续性](spacetime-effects.md#structural-change)区分稳定身份、变化前状态和后态延续，检查变量与参考图是否重新带回完整结构。

需要用空间推进局势时，让[地形参与行动](#terrain-action)：高差、通道、障碍与物件怎样限制原来的办法，又提供什么机会？可选择新空间改变行动条件，也可困在同一处，通过退路减少或争夺加剧推进。场景结构与转移服务于当前的动作和观看体验。

按这一刻的观看任务选择[机位与构图](camera-foundations.md#viewpoint)：沿攻击路线逼近可强调迎面冲击，侧向容纳双方可显出交锋与应对，扩大取景可揭示位置与退路的变化。贴近带来的压迫感与完整动作的可读性需要取舍，不把跟拍或一镜到底设为默认。需要力量与速度感时，结合起势、接触和余势，选择水迹、形变或碎屑等[环境响应](spacetime-effects.md#effect-interaction)；光效也可显出攻击轨迹与范围，遮挡程度服从当前需要看清的动作或关系。

只固定决定局面与观看回报的节点，让衔接动作保有发挥空间。对决定交锋成立的衔接，检查前一动作留下的朝向、支撑、重心、持物状态与双方距离是否支持后一动作；隐含的站稳、换脚、转身或重新抓握所需时间应纳入编排，必要时重排，不能只凭各动作单独成立就认定整串顺畅。这些是导演判断的依据，不要求逐项写入提示词；正文只落实影响交锋成立的关键衔接。普通过渡不逐关节规定；按[整片节奏](process-and-rhythm.md#rhythm)分配蓄势、交锋与收束，不逐招填写动作、运镜和特效栏目。

<a id="action-response"></a>

### 攻防接续写法

```text
〈人物A〉以〈具体动作〉逼近〈目标〉，〈人物B〉通过〈应对动作〉改变〈距离、姿态或可用路线〉。〈受此影响的人物〉顺着〈余势或新机会〉转入〈后续行动〉，最后〈可见的局面变化〉。
```

### 示例：门口争夺

```text
追击者横扫长棍，对手缩身钻进半开的木门，棍身撞上门框，横扫被截住。对手趁势推门，追击者收棍竖起，以棍尾撑住门缝。镜头从追击者侧后方跟到门边，停在侧面，看清门扇压住棍尾、两人隔门继续较力。
```

<a id="gatotsu-thrust"></a>

### 牙突式整身突进

以《浪客剑心》牙突启发的电影武打动作为例，适用于要突出准备构型、整身发动与突进距离的持械攻击。它是具体动作技法；多重虚影是可选的视觉叠加，二者可分别使用。

准备时压低重心、侧身收刀，持刀手在肩旁或侧胸形成支撑，刀尖先对准突进方向，另一手可前伸导向。按角色已有持刀手镜像适配，接住上一招的刀位与落脚。发动时由支撑脚蹬地，头肩、腰胯与武器沿同一方向加速位移；需要滑突观感时强调低位贴地掠进，避免只写伸臂刺出而缺少身体推进。

机位按观看目标选择：正面低位、位于突进轴线上的机位，可通过人物与刀尖迅速逼近、透视放大形成冲镜压迫；侧位或斜位可展示推进距离、交锋及对手应对。正面冲镜并非牙突的固定拍法；采用时避免无意后退抵消所需逼近感。

保留构型形成、起动、距离推进与结束点的可读过程。剪辑按动作本身的节奏选入出点；用户认可完整素材时，不为压短片长而只剩末端伸手的几帧。准备时长、脚法与终点按本片处理，不固定成某个秒数；也不强制每次以刺镜头结束。

```text
〈角色〉承接上一招短收成势，重心压低，〈武器〉先对准〈突进方向〉。支撑脚蹬地，头肩、腰胯与武器结成一束向前加速。〈机位〉看清构型、起动与整身逼近，在〈交锋、越过或迫近的节点〉结束或接续。
```

本例用于说明动作构型与整身推进的表达，不作为流派动作认证或固定时长要求。判断生成是否实现时，仍需核对实际运动及必要的准备、发动和完成过程。

<a id="terrain-action"></a>

## 地形改变行动

```text
〈人物〉沿〈已建立的路线〉行动，〈空间条件〉使〈原来的办法受限或新机会出现〉；人物借〈可用的结构或物件〉转入〈新动作〉，形成〈新的位置或行动条件〉。
```

### 示例：追赶行李箱

```text
小行李箱顺坡滚到长凳下，从另一侧钻出。他追到凳前来不及刹住，双手撑住凳背翻过去，落地抓住拉杆，却被仍在滚动的箱子带得又滑了一步。固定侧面全景，同时看清长凳两侧、翻越动作和落地后的余势。
```

<a id="speed"></a>

## 速度感

主体验要求运动速度感时，选择可辨的速度线索，如短时间越过可辨距离、近远景的运动视差、逼近与拉开的相对距离、动作加速与余势，以及环境和声音的同步响应。按本片取用，不要求全部具备或固定镜头形式；稳定跟拍同样可以通过环境运动显出速度。急迫、力量感与运动速度分别判断，不把所有张力都转成快速移动。

检查起步、障碍、接触和切镜之间是否无意停顿或重新起势，普通衔接是否占掉了冲势；核心动作与回报仍须可辨，不为快而全部缩成一闪而过。快节奏音乐可加强已有运动感，不能代替画面的位移与动作证据。

检查最终提示词与素材中，除速度标签外是否还有足以支撑预期体感的具体安排；缺少时补足线索或调整拍法，不要求删除有效的风格词。预演涉及速度判断时，结合时间标记和连续运动检查节奏，不凭静态关键帧或路径可通行作结论；不能按正常速度观看时保留体感判断的限制。


<a id="continuity"></a>

## 动作与空间衔接

先在文字或简图中明确人物、动作目标、主要道具、通道和摄影机的相对位置，再将关键过程排出来。方向以场景地标或人物自身为参照，转写成画面左右时核对观察侧。

接触、交接、避让、跨越或同步动作按下列顺序核对。承担回报或存在空间、支撑、持物歧义的节点写清必要过程；普通过场不必逐项列五步，但会改变动作含义或可行性的关系仍须在设计时确定：

1. **开始状态**：谁站在哪里、面向哪里、哪只手持有什么，目标距其多远，哪条路能到达。
2. **触发与准备**：什么使行动开始，身体或道具怎样进入可执行的位置。准备可与其他内容同时发生，但不能凭空省略。
3. **关键过程**：谁对谁或什么施力、接触、交出、躲开或经过；接触点、通过顺序及必要的身体部位在哪里。关键支撑须核对接触面的形状、尺度与朝向能否承托，通过处须有实际余量；会套入、滑脱或卡住的关系，先调整构造、位置或动作，再写后果。
4. **回应与后果**：对方、物件或环境怎样变化，动作怎样影响下一步；把仅靠作者解释的因果改为画面能读到的依据。
5. **结束状态**：谁持有什么、停在何处、朝向怎样、动作是否仍在继续，为下一段留下什么条件。

同时安排摄影机能否看见上述关键证据。必须看见接触的过程时，不用切镜、烟雾或突然换景省掉它；回报只需结果时，也不机械补齐全部准备。动作发生在身体背后、画框之外或被另一人遮住时，先改观看侧、站位或顺序。

需要重量与接触感时，把支撑交接写到动作链里：蹬离窗沿→越过空隙→抓实扶手→肩臂承重→身体摆回门槛。重点是余势如何继续，而不是逐关节规定角度与毫秒。递物和接力还可由物件轨迹、相同方向或声音承接。

用户限定某个标志动作的次数，或实际结果把它重复到其他相似节点时，明确它发生在哪一段，并给其余节点写不同的可见完成方式。例如只在中段跃下后翻滚卸力，其他落地以屈膝缓冲或两步泄力接着前进。只处理已限定或已观察到的重复；体操、舞蹈等有意重复同一动作时，保留其节奏与变化。

穿越入口或障碍承担关键动作时，用当前视点下的地标说明起点、通道和终点，画面左右不能代替通道两侧的空间关系。涉及门扇等活动障碍时，按剧情明确通行前后的状态；依赖穿越完成的后续动作，以主体实际通过为触发。

[动作匹配](editing-and-continuity.md#match-action)可以维持同一动作的连续，也可以用相似动作连接不同时空。前者接住动作阶段，后者让环境或人物状态的差异产生意义。

形态或场景转换时，按[转场中的持续追踪对象](editing-and-continuity.md#transition-tracking)安排可辨认线索。需要让相似动作在前后产生不同意义时，用[动作重复与变奏](process-and-rhythm.md#action-variation)，把变化放在行动方式、对象或回应中；次数和切镜服从本片节奏。

<a id="portal-traversal"></a>

## 空间门穿越

用于主体通过可见空间门或裂缝，从一个空间进入另一个空间。门如何出现及其造型按作品另定；本技法处理门两侧的空间关系、主体通过及抵达后的场景衔接。

先分别明确起点A与目的地B。从A观察时，门外是A，门内从首次显露就属于B，包括开口底端和远处背景；不能只替换天空而把A的地平线带进B。从B回望A时，同样按门框限定来处的可见范围。

主体与摄影机各自的接近、过界路线分开安排。可以侧拍主体通过后切到B，也可以跟随主体连续穿过；取景须让观众追踪同一主体从门外经过边界、进入另一空间的关键过程。按需要保留身体前后部位通过的证据，避免用主体叠化或只换背景代替穿越。主体过界时附带的造型变化属于可选内容，不替代主过程。

抵达后先决定是否还看见来处。需要完整换场时，建立独立的B场景，画幅边缘与主体下方也属于B；有意保留身后入口时，A应限制在门框内。具体用切镜、连续跟随、保留或关闭入口，由本片观看体验决定。主体的支撑、受力、光色与环境声接住B的条件，如落地、浮水或失重，不沿用与目的地矛盾的起点状态。

检查旧景残留时，向前核对门内首次显露的背景，再检查主体过界与目的地建立的交接点；只在末段追加“不出现旧景”可能漏掉前面已经混入的空间。修改后仍需核对实际结果，不以补过约束证明换景已成功。

<a id="physical-response"></a>

## 受力与可见响应

人物、物件或环境的重量与力度，需要通过响应被看见：重物启动时可用支撑压缩、身体借力及启动迟缓；减速或转向时可用越过目标后的回摆或逐步收住；表面摩擦可用滑行距离、减速与停点；风力可用不同形状、支撑或质量的对象出现不同幅度、滞后与恢复。按材料和本片运动选择线索，写清作用从哪里来、经哪里传递、留下什么后态，不为“真实”统一加弹跳或抖动。烟雾、液体、碎屑等效果的路径与实景响应见[特效与实景联动](spacetime-effects.md#effect-interaction)。
