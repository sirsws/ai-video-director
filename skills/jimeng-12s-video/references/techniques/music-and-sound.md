# 对白、歌唱、配乐与声音

按[方法调用与复用规则](../creative.md#method-use)读取本片相关小节，已有充分决定直接沿用；对白、演唱、配乐、拟音与声画组织按本片需要取用，不要求每片包含所有声部。

<a id="sound-plan"></a>

## 听觉过程与声部安排

沿用项目已定的音乐偏好，分别决定角色是否开口、画外是否有歌声；无角色对白也可以有强烈的画外歌曲。参照的主要吸引力包含旋律、唱腔或歌曲时，把对应特征纳入设计，不只借画面。

按段落决定观众此刻主要听什么，哪些声音提供空间、行动证据或情绪。把进入、让位、同步与结束放在对应画面里：

| 声部 | 必须落实的内容 | 具体冲突处理 |
| --- | --- | --- |
| 对白／独白／心声 | 谁说、对谁说、逐字文本、语言、意图、画内或画外、演法及起止位置 | 多人轮次明确；不让同一时间的口部动作、歌词和台词分别指向不同内容。 |
| 歌唱 | 画内演唱或画外歌曲，语言、唱法、乐句及固定程度，是否承担对口型 | 主角演唱时把换气、口型和身体动作共同安排；跨镜仍在演唱不改成背景歌曲。 |
| 环境声 | 房间、风雨、人群、街道或机械声来自哪里，跨镜是否延续 | 环境改变时决定保留、淡出或切换，避免无原因的声音断层。 |
| 动作与效果声 | 哪次接触、开关、落地或变化发声，声源与可见事件怎样同步 | 声音应加强实际发生的动作；没有对应接触时不能靠巨响伪造动作完成。 |
| 音乐／静默 | 主要旋律、律动、音色或唱法，进入、发展、保持、转折与结束 | 需要听懂台词时局部让位；需要身体冲击时让节奏、动作声和画面配合；静默说明保留哪些现场声音。 |

音乐须形成具体听觉过程，不能只列曲风和乐器。进入、发展、让位、结束及演奏力度与混音音量的区别，按[配乐、情绪与编排](#score)和[编排写法](#music-direction)落实。持续托住同一种情绪也可以，不要求每段升级或每次切镜都有重音；声画反差写清两者各自在做什么及其并置作用。

<a id="dialogue"></a>

## 对白推动行动

对白可以是人物正在采取的行动：试探、命令、讨价还价、掩饰或误解，让另一方回应或使下一动作改变；不只用于解释画面、交代到场或结尾点题。需要时先确定说话者想达成什么，再写台词、回应与动作发生的关系；反应也可以无声；是否增加对话人物，按人物功能、观看收益与本次授权决定。

当拍法有实质取舍时，判断加入、移位或拿掉一句话／一段音乐会怎样改变观看体验。删掉后没有损失的解释可以省；能驱动事件或改变人物读法的声音应与动作一起保留。无对白也能靠动作、拟音或沉默成立，不按台词数量、音量或声部数量判断效果。

自行写作或获准改写台词时，用下面的[角色语言](#character-voice)形成这个人在当前关系中会说的话。固定原话保持逐字不变，表演方向另写，不混进引号内。发现原话与预定演法或时长冲突时，调整演法、落点或提议改词，不能假借“更自然”静默改掉。

<a id="character-voice"></a>

## 角色语言：从各自关心的事长出台词

写人物对白或处理“人人说话都一样”时，先看各自注意什么、认什么证据、想把关系拉近还是推远，再选词句。隐瞒存在时考虑怎样回避；压力变化时考虑语言怎样变形。这些是可选的写作抓手，不是五项必填表。同一个人对家人、上级和陌生人可以换说法，诗性、书面、笨拙或极简也可以符合人物，不统一改成流利口语。

例如雨夜摊棚漏水，电工看见水沿电线逼近插座，伸手拔电，说“先断电”；摊主挡住他的手，眼睛仍盯着电炉上的锅，说“这锅熄了，今晚房租谁交？”差别来自两人正在保的东西及其行动，之后怎样回应由本场决定，不能只靠一人说成语、一人说网络词来区分。此为原创方法示例。

需要判断差异是否成立时，可暂时交换两人的台词，看各自的目标、证据或关系是否仍完全成立；若只有口头禅不合，回到真正不同的关注与处事方式修词。普通应答、有意同声或已经固定的原话不因可互换就算错误；也不为区分人物硬加争执、秘密或口癖。

既有人物的辨识度依赖说话方式时，把本次要保留的态度落实到声线、咬字、重音、停连与句尾中的关键选择，并与视线、距离和动作相接；只有“低沉、微沙、温柔”不足以区分人物。没有原声核验时标为本次演绎，不声称复刻原配音；亲密场景也不能无依据抹去角色的戒备、傲气或讥诮。

本节适配自 Drama 固定版[人物声音 §6、交换说话者 §10.5](https://github.com/zenstory-ai/drama-skills/blob/7e6336047ddb3c6344b3c3966a81ad8008d23c11/skills/short-drama-write/references/dialogue-craft.md)，直接用于本次台词与演法，不另建声音卡。

<a id="sync-text"></a>

## 台词、同步与字幕时间

有台词时，确定它落在哪个动作前、动作中或反应后；语速、停顿、重音、气息按人物正在做的事选择。估算整句加必要停顿能否落入可用时间，不能把长台词、复杂动作和反应都塞进同一瞬间。已有实际朗读计时就采用；否则普通中文可暂按约 4—5 字／秒、慢说或强调按约 3—4 字／秒粗估，再结合演法估计停顿，不按标点机械加时，也不重复计算已包含的停顿。未实际计时须注明估算。超时先比较调整措辞、演法、动作并行或画外表达，固定原话不能自行改掉。

对口型承担主要效果时，选能辨认发声者和嘴部的取景，明确轮次与听者反应，避免关键字句全落在背脸、遮挡或剧烈头部转动中。风格确需这些动作时另选句子落点或画内／画外安排，不一律取消动作。

字幕范围：非中文对白沿用中文字幕要求。歌词字幕仅用于主要人物演唱的外语歌词；背景歌曲不加歌词字幕。主要人物的演唱跨镜头延续时，不因暂时不在画面中而改算背景歌曲。按歌曲名和段落调用原歌时，不臆造未核实的歌词。用户另有要求时按本次要求执行。

字幕逐句对应原文，落实指定文本或译文来源、出现与替换时机、阅读时间和全画布中的位置；分屏时明确共用一份还是各格分别显示。字幕不能盖住脸、接触点、产品证据或本片笑点；画面信息和文字同时过密时调整时机与构图，不能只写“字幕清楚”。

需要翻译或本地化时，将说出的原话、发声语言或口音、字幕译文及其简繁体分别处理；书写简繁不决定说普通话还是粤语。仅修改字幕不改台词、发声方式或提示词全文。按指定受众核对称谓、词义与惯用表达，简繁转换按语义处理，不机械替换单字；意译字幕与逐字台词有意不同的，分别标清。用户已指定的内容直接沿用，只补问会改变本次文本或表演的缺口。

需要精确字形、多个语言版本、无字画面、配音或分轨交付时，明确哪些由后期完成及所需底稿：逐句文本、说话者、入出点、干净画面或音轨。当前入口不支持的素材类型不写入上传清单。生成对白、音乐与字幕的实际同步、清晰度和内容仍需核验；在编译前排定这些关系，不让生成端猜测。

<a id="audio-repair"></a>

## 对白与同步出现问题时

先核对实际使用的句子、发声者、画内／画外安排、声音落点与素材，再区分漏字或改词、演法不符、口型、没说完、配乐遮挡。当前宿主不能审听时，听感与字句采用用户明确反馈，不写“已听清”。

用户已有尝试可比较时，按[制作中的诊断比较](../production-and-delivery.md#repair-decision)区分单项核验与多项明确冲突的联合修复，记录采用和失败的尝试，不能只挑成功一次。固定台词不自动缩短，人物动作不自动取消；换为画外声、调整句子落点或改取景时说明会损失的表演或连续性，涉及锁定内容先交由用户决定。

没有实际结果时，只做容量和冲突判断，不要求每片另做付费朗读或生成测试。连续改写没有新增证据时停止堆修饰词，保留执行未知。

<a id="song"></a>

## 歌唱与节奏

角色演唱承担主体验时，先考虑值得听、适合人物唱的乐句和唱法，再让画面回应。接唱、错拍、和声或中断能改变关系：第一次尾句无人回应，第二次对方接住尾音，原主唱把声音与身体位置让出来。单人也可让同一句从试探唱到笃定，或由伴奏、空间和摄影机回应他。

按作品需要决定[歌词的固定与生成](#lyric-control)。

歌词、BPM与[唱法／Flow](#vocal-phrasing)分别表达：相同速度和歌词仍可有不同的入拍、重音、字音疏密、停顿与拖音。只写影响本段听感的处理，按乐句安排呼吸与衔接，让需唱出的内容、留白和收束容纳在本段可用时长内。

同一乐句或持续尾音跨镜时，标明谁开始、哪一镜延续同一次发声、谁在何处接唱或收束，并安排画面此时看谁；切镜不默认重新起字。多世界快切可改变配器、力度或空间感，同时交代同一旋律或律动怎样继续，不把每镜重开音乐当作连续。

需要明确旋律过程时，按关键乐句描述起音高低、上行或下行、峰值及回落，并说明句尾怎样接入下一句；需要具体音高时可用唱名表达。

动作既可命中重音，也可延后制造等待；高音、大动作与全编制可以共同完成强峰值，接唱或停顿也可成为峰值。具体选择服从这首歌和人物，不为表情特写打断已成立的持续演唱。局部反应按需要查[情绪表达](performance.md#emotion-expression)或[连续表演](performance.md#continuous-performance)。

<a id="lyric-control"></a>

## 歌词的固定与生成

按作品的歌曲目标与措辞要求决定歌词的固定与生成。复刻既有歌曲时，明确歌名、歌手／版本与可定位的段落，保留原歌旋律及对应歌词；“思念段”“拥抱段”等情绪概括不能独立定位乐句。已有用户提供或可复用的指定歌词时，在允许引用的范围内保留准确文本；其余情况用准确的段落或起止定位，不臆造歌词。用户要求“仍用／沿用”已有作品的歌曲时，先读取该作实际音乐段，继承其歌曲、段落、编配和唱法要求，只调整本片声画落点，不自行退化成歌名加氛围。创作新歌词时，剧情、接唱或观看回报依赖指定措辞的部分写明原文；其余部分可按视角、意象与情绪走向交给模型生成。生成正文表达歌曲目标，未命中结果的接受范围留在交付判断中。

```text
复刻既有歌曲：〈歌曲与歌手〉，由〈演唱者〉演唱〈目标段落〉，保留〈原歌旋律及对应歌词〉。〈确需逐字锁定时补充原文〉。
```

```text
创作新歌词：由〈演唱者〉演唱。〈必须固定的原文〉；〈允许生成部分的视角、意象、情绪走向与乐段要求〉。
```

<a id="vocal-phrasing"></a>

## 唱法与Flow

要形成旋律歌唱时，可用持续元音、连音、音高跨度、乐句呼吸或长短音对比组织乐句。若输入同时要求低音区逐字短音、密集强拍和命令式停顿，先检查这些安排是否正把演唱推向念唱，再调整起作用的唱法；只加“不要说唱”不能替代可听的乐句结构。面部态度与唱法分别设计，冷脸不自动等于低沉念白。

```text
〈演唱者与声音特点〉，〈入拍位置、字音疏密与重音安排〉；在〈乐句节点〉〈停顿、连唱或拖音〉，以〈句尾处理〉接入下一句或收束。
```

<a id="score"></a>

## 配乐、情绪与编排

按音乐对人物、关系与观众期待的作用选择配乐或留白，不默认克制表演需要弱配乐或无配乐。明确是画外配乐还是人物在画内演唱，后者对应演唱者与表演动作，不只标作BGM。无对白、无配乐与完全静默分别判断。

画外人声按本片目标选择有词歌曲或无词唱腔，明确乐句、唱法及其与画面的关系。用户或本次方向要求歌曲时，落实目标歌曲段落，或按[固定与生成](#lyric-control)设计歌词；词句不必固定时可交给模型生成。无词唱腔可独立选择，不能仅因存在人声就视为落实歌曲要求。歌词可承担态度、叙事、记忆点或配合旋律表达情绪，不必逐句解释画面；画外歌唱不增加角色对口型。有对白时按节点安排歌声与对白的前后或层次，避免争夺语言注意力，不笼统压低整首歌。

配乐承担人物身份、关系转向、观看推进或高潮时，先确定它要把人物、关系或画面推向什么感受，以及音乐与画面怎样配合，再选择相应曲风、配器与演奏。当前入口以文字引出指定既有歌曲时，落实歌曲／版本、目标段落，以及曲风、拍号、BPM、调性、情绪五项基础设定，再选决定辨识度的唱法与配器；已有用户指定或明确要求沿用的音乐段直接继承。参数须区分已核实的原曲信息、本次编配和沿用的输入设定；未知且不允许改编的原曲参数须核实或保留缺口，不编造。该要求不扩展为原创器乐、环境声等所有声音任务的必填表。

可直接设计原创音乐；使用歌曲或歌手作参照时，注明目标段落及要沿用的旋律、律动、配器或唱腔特征，区分借其风格与指定旋律。需要忠实原版时，核对确需沿用的已知信息；允许编配时作出明确选择，不把本次设定当成原版事实。

曲风、配器与情绪相近不等于指定旋律可辨识；文字设计不作为旋律命中的证据。

需要用短动机建立辨识度时，把起作用的节奏长短、音高轮廓、主奏音色或回应关系写具体，例如铜管主题靠“两短一长”的节奏辨识。设计复现或高潮变奏时，说明同一材料怎样返回或改变。器乐与演唱都适用，不必填齐各项，也不固定音数或强求复现。

配乐有作用时，确定片中乐段的进入、推进与结束方式，可从主乐句直接进入，不必另加前后奏；与画面关键变化可同步、提前或延后，不机械强调每个动作。旋律、和声、配器与音量服从情绪走向，不以音量最大等同于高潮。对白或关键动作声需要更清楚、且本段要维持音乐连续时，局部降低配乐并保留其可闻性，之后按设计恢复；有意切断、静默或不再恢复时，明确节点并保留该选择。歌唱人声与伴奏共同成立，不因持续有人声而把伴奏全程压弱。

演奏力度、音色与混音中的相对音量分别表达：“轻柔”可以指演奏与音色，不自动要求降低伴奏音量。伴奏承担律动、辨识度或情绪推进时，说明哪些声部应清楚可闻、怎样与人声配合及何时展开；“人声居前”不能替代这一关系，也不默认所有作品都要加大伴奏。

<a id="music-direction"></a>

### 编排写法

按当前音乐作用保留需要的字段；指定既有歌曲时按上文落实基础设定，其他声音任务按需选择。

```text
音乐〈纯器乐／有词歌曲／无词唱腔〉，〈用作画外配乐／由谁在画内演唱或演奏〉，承担〈情绪、人物或事件作用〉。
〈使用参照时〉参照〈歌曲、歌手或目标段落〉的〈曲风、旋律、配器或唱腔特征〉，明确〈借其风格／指定旋律〉。
〈指定既有歌曲：曲风、拍号、BPM、调性、情绪与律动；其他任务按需选择〉。
〈音色与唱法或器乐演奏方式〉。〈决定辨识度的配器或音乐动机〉；随〈片中节点〉，〈声部、力度或乐句怎样推进与结束〉。
〈需要明确混音关系时〉〈关键伴奏声部及其可闻程度〉与〈人声／其他声音〉形成〈相对层次与配合〉。
```

<a id="sound"></a>

## 环境声与动作拟音

杯底落到木桌的短闷声、指甲刮过杯壁的尖细声、液体晃到杯沿，承担不同触感。声源动作、材质、距离和遮挡比“真实音效”更具体：门后的声音先闷着传来，门开后变清，观众才看见是谁。

声音还可通过回响或共鸣交代空间：同一脚步从石厅较长的尾响走到室外较干的近声，或敲击经空金属腔体带出共鸣。按实际材质、距离与场景设定选择，不给所有室内统一加回声。

只突出当前起作用的声部。歌唱时拟音可退后，受惊前可抽走环境底声，纯静默可延长等待；不必为每个物体配声。

<a id="sound-as-music"></a>

## 环境声入乐

将场景或动作声音组织成节奏型、音乐动机或乐句回应，明确它与鼓组、人声的进入及交替关系，使声音同时承担题材辨识与音乐推进。

```text
马蹄声先建立律动，鼓组接入后继续与底鼓呼应；说唱句尾留空，由短促的枪械机械声回答。
```

<a id="counterpoint"></a>

## 声画反差

喜剧可利用所说与所做、听觉预期与可见结果的错位。配乐可把小事郑重其事地托大，也可在人物失控时继续若无其事；对白可先建立预期，再被动作推翻。选择适合本片的关系，写清对应节点与变化，不只写“反差音乐”或套用固定音效。其他类型也可用声画错位形成张力或情绪。

<a id="sound-bridge"></a>

## 声音跨镜：先入／延留

### 先入／J cut

```text
画面仍是〈A的动作与构图〉，先响起属于〈画面B〉的〈声音及起始内容〉；到〈切镜节点〉切到〈B的画面〉，同一声音接续〈后续内容或变化〉，让观众认出〈声源或两画面的关系〉。
```

### 延留／L cut

```text
〈画面A〉中〈声源与具体声音〉正在进行；在〈节点〉切到〈画面B〉，A的声音继续覆盖〈B的动作或反应〉，到〈声音结束或交接节点〉转入〈后续声画状态〉。
```

### 示例：先入

```text
空餐桌上摆着一只酒杯，先听见热闹的碰杯声。切到聚餐中的人们，杯子刚刚分开，清脆余响连着笑声继续，镜头停在举杯却迟迟没喝的人脸上。
```

<a id="offscreen-consequence"></a>

## 画外行动，画内后果

让观众从声音或可见后果理解未入画的事件；主要期待是动作本身的过程与完成时，应把动作放进画面。

```text
〈画内主体及正在进行的动作〉。〈画外方位〉发生〈事件〉，画面通过〈声音、光影、震动、物体位移或其他可感后果〉让事件成立；〈人物反应或物体变化〉继续推进，镜头停留在〈关键后果与画面落点〉。
```

### 示例

```text
男子端坐喝茶，画外左侧突然轰响，桌面一震，茶水荡向杯沿。他视线仍落在杯中，只伸出食指扶稳快要滑下的杯盖，待水面平复后继续喝茶。
```

<a id="fixed-caption"></a>

## 固定压字

```text
【固定压字】
字幕：“〈压字原文〉”。从0秒持续到〈片长〉秒，全程固定在〈不遮挡关键内容的安全区位置〉，〈字号、颜色与描边〉，与背景有足够对比，清晰可读。该字幕只出现一份，内容和位置保持一致。
```

只有本片明确要求或已经出现相应问题时，才补充其他文字限制；不默认删除场景标牌或用户指定的其他文字。
