# 光线、材质与影像质感

按[方法调用与复用规则](../creative.md#method-use)读取本片相关小节，已有充分决定直接沿用；据此按本片需要选择光色、材质和成像处理。

<a id="light"></a>

## 照明与可读性

光影可承担人物塑形、空间分层、注意力引导和信息揭示。照明关系可表达为“光源及位置 → 受光对象 → 明暗分布”：单窗光、门缝漏光、荧光顶灯等名称可作起点，再按观看需要明确方向、照射范围和阴影。写实场景可由主光、环境光与墙面反射共同建立可信关系；风格化作品按自身影像规则设计。

光的软硬、明暗反差与整体亮度分别选择。柔光的阴影边缘过渡柔和，较少补光时也能保留深暗面；明亮环境中同样可以有锐利日影。局部照明或遮挡可让次要区域退暗，背景局部提亮也能衬出暗衣人物。显露或隐藏哪些表情、动作和背景信息，由当前观看任务决定。

| 选择 | 怎样落实 | 应检查的效果 |
| --- | --- | --- |
| 主光方向与高度 | 正面偏侧、侧面、侧逆、顶光或低位等，写明相对人物或物件的位置 | 哪些五官、身体、结构和接触点被照见，哪些被遮住；方向改变后人物读法是否仍成立。 |
| 主辅光关系 | 暗侧保留多少细节，是否用环境反射或辅光提亮，背景比主体亮还是暗 | 需要读懂的动作不能沉入黑处；高反差是否把身份、材质或功能证据毁掉。 |
| 光质 | 明确软边或硬边阴影、照射范围与过渡 | 人物塑形、材质纹理及画面气质是否相容，不把“柔”当成全部变平。 |
| 色彩与色温 | 主光、环境光及服装／物件各自的颜色，主次色与对照关系 | 人物与背景有无区分，肤色和产品颜色是否符合目标；冷暖的情绪由处境决定。 |
| 材质响应 | 粗糙、金属、玻璃、湿面、布料怎样反射、透射或受光 | 高光是否说明结构、会不会挡住标识，变化是否由物体、光或视点的相对运动产生。 |
| 变化节点 | 开门、转身、光源开关、遮挡变化、换场或风格转换带来什么受光变化 | 变化由什么触发、照到谁、信息或感受怎样改变，不为每次情绪变化强行闪灯。 |

<a id="clarity-control"></a>

## 清晰度与风格约束

需要明确清晰度时，在全局设定或相关镜头中说明必须清楚的主体、关键边缘、纹理或动作，并让对焦服务这些对象。`4K`、`8K`、相机或镜头名称只能表达倾向，不能替代这些可见要求。需要胶片、柔光、手持、浅景深、颗粒或运动拖影时，限定其强度和作用范围；确有具体问题需要排除时再写针对性限制。

```text
〈需要清晰的对象与时段〉边缘或细节可辨，焦点〈怎样保持或交接〉；〈关键表面〉保留〈所需纹理〉。〈有意柔化、失焦、颗粒、手持或拖影的对象、强度与时段，无则删除〉。
```

例如需要主体清楚、颗粒与手持均较轻的版本时，可写“极轻微细颗粒不覆盖人物与关键纹理，稳定器手持微晃，主体持续清晰”；需要浅景深时，只要求主体清晰，不把背景虚化列入反向限制。

<a id="light-change"></a>

## 光色与变化

光色可绑定具体空间与表面：室内暖桌灯和门外冷天光分别照到人物的身体与伸出的手，跨门动作带出光色过渡，情绪含义由人物处境建立。动态光影可随人物、光源、遮挡或机位变化组织；例如走廊暖光从门缝先照到握门把的手，门推开后光带变宽，逐渐露出迟疑的表情。连续段落中让受光面、阴影与反光随相对位置变化，形成同一空间的照明关系；只有机位运动时，观察到的反光可以改变，不意味着固定光源的投影也随之移动。

设计[反射或透射形成的照明](#redirected-light)时，明确光源、改变光路的表面与最终受光区域，以及它们的变化怎样影响亮纹或颜色。选用[镜头眩光](#lens-flare)时，另看强光相对镜头的方向与遮挡；眩光改变成像，不等于场景受光改变。按本片观感与关键表演的可读性选择变化幅度和时机。

风格名称可帮助调用知识，再用决定本片观感的特征落实为[影像质感片段](#look-system)。物体表面的粗糙或光泽，与成像的颗粒、锐度及高光过渡分别选择，并让服装、场景与光色相互配合；不逐项填满，也不将复古、胶片或某位导演固定成一套配方。颗粒、雾、器材词与分辨率标签只在需要对应效果时使用，不当作画质保证。

<a id="look-system"></a>

## 风格与可见特征

需要整体的摄影、光色、表演和声音组合时，沿用[作品方案的整体处理](../shooting-treatment.md#style-treatment)；本节落实其中的光色、材质和成像选择。

确定全片哪些写实程度、空间关系、光源、色彩、材质与介质质感保持一致，哪些按观看需要改变。靠美术关系组织的多个画面，要有贯穿的视觉联系和各段新增的观看内容，可用形态、比例、材质、构图或空间关系的重复与变化连接。

同一画面混合媒介时，把不同处理分配给具体对象或图层：人物、产品、环境、覆盖图形各自采用什么绘制或成像方式，哪些共同参与光照、遮挡和运动，哪些作为有意独立的图形。再确定它们共享的色彩、构图或节奏关系，不把多个风格名称并列后交给生成端猜比例。例如真实玻璃瓶保留折射和反光，后方是手绘街景，平面箭头沿瓶外轮廓移动；箭头不变成实体，也不穿过本应遮挡它的瓶身。纯二维的图层与时序继续使用[二维动画](animation.md)，不在这里重复展开。

风格转换时，按观看目标明确变化的对象、范围与层次：人物、服装、道具和环境中哪些改变、哪些保留；变化涉及色彩与成像、表面材质，还是五官比例、轮廓和绘制方式。需要漫画化等重绘效果时，写出最有辨识度的结构或线条变化，并说明人物与环境是否同步重绘，避免仅用换色或换背景表达结构变化。局部转换与全画面转换均按本片需要选择，不默认所有对象一起改变。明确开始条件、变化过程、完成标志，以及衣物、道具、影子和声音怎样跟随；结构变化还须按[状态连续性](spacetime-effects.md#structural-change)保留后态。

```text
〈风格方向〉。〈光源及方向〉在〈主体与环境〉上形成〈明暗与层次〉，〈主要色彩〉分布于〈服装、物件或空间〉；〈关键表面〉呈现〈纹理或光泽〉，〈需要的成像特征〉形成〈当前段落的观感〉；世界或风格转换时，分别表达前后特征与衔接。
```

### 示例：侧逆光与粗粝表面

```text
粗粝的写实影像，低位侧逆光勾出人物轮廓，背景较亮，人物暗面保留动作所需的细节；衣料纤维与磨损表面清楚，亮部偶尔显出金属光泽。
```

### 示例：硬光与鲜明色块

```text
复古广告影像，直射日光形成边缘清晰的阴影，鲜明的环境色与深色服装相互衬托，肤色保持自然；少量细颗粒与柔和的高光过渡统一观感，快速运动处保留自然拖影。
```

### 示例：局部照明与暗部空间

```text
局部顶光照亮动作所在的区域，周围空间逐渐退暗，人物与暗背景保持可辨的明度或色彩差异；哑光表面保留纹理，光滑边缘出现少量亮点，暗处仍能辨认决定空间关系的边界。
```

### 示例：观众席手机记录

```text
镜头从一位观众的位置观看舞台，随关注的孩子小幅摇移，前排观众偶尔短暂遮住画面边缘；调整取景时短暂失焦，随后重新跟住表演，现场笑声与脚步声保留。
```

<a id="dark-hong-kong-wuxia"></a>

### 示例：暗调港式奇幻武侠

适用于需要凌厉、神秘、具有实体重量感的奇幻武侠场面；可独立用于人物或动作镜头，也可与万剑等群体奇观组合，按本片选用。

```text
暗调港式奇幻武侠电影的真人实拍质感，背景深暗，暖橙火光从侧面照亮人物面部、双手与粗粝地面，冷青侧逆光勾出金属、发丝和衣服边缘。强烈明暗反差，人物暗面仍保留必要细节，旧钢铁、石材、衣料与皮肤纹理真实可辨。动作近景采用浅景深，近处快速运动物件失焦掠过，中景人物及关键动作清楚，后景保留层次；快速运动带有方向性的自然拖影，金属边缘随运动闪出反光。
```

这是具体影像组合示例。场地、衣装、武器与配乐另按作品选择，不把这套光色和材质写成所有武侠作品的固定要求，也不据单次应用推定稳定效果。

<a id="source-look"></a>

## 影像来源怎样影响画面

用户要求具体拍摄来源时，选择真正帮助辨认它的行为和成像特征；同一来源可以很干净，不默认加糊、加噪声或遮住关键动作。

| 来源 | 可以选择的特征 | 与本片动作的关系 |
| --- | --- | --- |
| 手机记录 | 手持调整、短暂自动曝光或对焦变化、有限动态范围 | 记录者根据发生的事调整取景，反应可稍迟；关键动作仍要读清。 |
| 直播／网络视频 | 固定或有限机位、界面文字、适量压缩痕迹 | 是否有界面按用户要求；表演朝向、遮挡与字幕区域按实际画面安排。 |
| 监控 | 固定安装位置、较广视野、持续无人操作的观察 | 通常不追随人物推拉摇移；若摄影机主动响应，应有设备或风格依据。 |
| 老胶片 | 颗粒、轻微片门抖动、高光过渡、色彩或磨损 | 选择年代和介质需要的特征，不把所有划痕、漏光、褪色同时堆上。 |
| 棚拍／产品广告 | 受控高光、稳定曝光、干净背景与精确运动 | 材质、轮廓、标识和操作证据仍有区分，不用泛化的“奢华”表面覆盖产品特点。 |

来源改变时同时检查摄影机行为、声音空间与成像是否相容。自拍、镜面或手持第一视角依赖真实拍摄关系时，结合[机位与构图](camera-foundations.md#framing)及[动作与空间衔接](action-and-staging.md#continuity)核对。观看来源的选择不自动改变故事、造型或人物身份。

<a id="color-check"></a>

## 光色失效与交付核对

颜色与质感失效时，按原因调整：主体和背景混在一起，先改光位、明度或色彩分离；过度调色损害肤色、产品色，收回冲突风格词并明确保留对象；跨镜不一致，核对光源、时间、主色与材质是否继承。同镜内无意闪烁或照明跳变时，检查固定光源是否被写成多次变化、人物或遮挡变化是否解释了受光改变，再修正冲突；有意闪烁保留其触发、范围与节奏，不一律改成稳定光。生成后仅调色不一致可安排调色；照明方向或信息显露本身错误则须回到拍法。

涉及专业色彩交付时，把源素材、外观参考、工作／输出色彩要求、需要保住的肤色与产品色、后期检查项写入同一方案。ACES、HDR、LUT 或分辨率名称不证明已实际达标；只在本次确有对应交付要求时安排色彩管理、转换与检查，不把多个互相冲突的技术标签堆进提示词。

<a id="material"></a>

## 材质与效果

材质通过当前光线下的反射、透射、纹理或形变显现。人物经过窗格投影，光带先扫过粗布再到金属饰件，漫反射和移动亮点形成不同质感；雨水让窗外霓虹散开，人物靠近玻璃又改变反射关系。可由人物、机位或光源运动[显出材质](#material-response)，也可保持光线不变，让人物状态与它形成对照。

[受控材质转换](spacetime-effects.md#material-transition)可把质感变化本身作为事件：选择哪些属性改变、哪些特征保留，并让透明度、反射或纹理变化在当前光线与机位下可辨。

质感变化与结构变化可分别表达：[部件重组](spacetime-effects.md#component-reassembly)说明原部件怎样成为新结构；[特效与实景联动](spacetime-effects.md#effect-interaction)选择当前镜头需要的遮挡、光影或物体响应，使效果进入同一影像世界。超现实作品也可按自身规则建立这些关系。

<a id="material-response"></a>

## 材质的动态显现

```text
在〈已有光源关系〉下，〈物体、人物、光源或机位的变化〉使〈表面〉出现〈反光移动、透光、纹理显露或形变〉，与〈另一表面或先前状态〉形成可见差异；〈承载关键动作的部分〉仍清楚可辨。
```

需要让局部变化可比较时，保留同光线下未改变的邻区或稳定基准。例如湿斑扩展时，仍让干纸边缘入画，关键边界不被剪影、反光或裁切消掉；全纸同时变暗不能替代湿斑边缘的连续扩散。

<a id="redirected-light"></a>

## 反射或透射形成的照明

```text
〈光源及位置〉经〈反射或透射表面〉，在〈受光区域〉形成〈亮纹或色彩分布〉。随〈光源、表面或受光对象的变化〉，〈亮纹或颜色怎样移动、变形或改变明暗〉。
```

<a id="lens-flare"></a>

## 镜头眩光

```text
〈强光源相对镜头的方向与遮挡关系〉。随〈机位、光源或遮挡的变化〉，〈光晕、条纹或光斑〉在画面中〈出现、移动、增强或消退〉，使〈画面区域〉的反差与清晰度发生〈所需变化〉。
```
