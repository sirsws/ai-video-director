# 过程组织与节奏

按[方法调用与复用规则](../creative.md#method-use)读取本片相关小节，已有充分决定直接沿用；据此按本片回报组织过程与时间。

## 过程设计

围绕本片主要观看回报，选择承载过程的人物、物件、群体、空间或图形，明确它在持续期间怎样发展。区分主体自身的变化与摄影带来的观察变化，让运动、表演、摄影、剪辑和声音共同形成过程，避免只给几个结果画面补上移动效果。加入或传播的过程本身是观看重点时，让观众跟住可辨认的人物或局部，看见其从未参与到参与，并在后续延续这一变化。

## 十二种运动方式

| 方式 | 用来组织什么过程 |
| --- | --- |
| 描画 | 线条、路径或轮廓逐步生成，引导注意力、建立路线或显出结构。 |
| 分支 | 一个主体、动作或来源分出多条路径与响应，展开选择、扩散或规模。 |
| 汇合 | 分散对象逐步聚集、对接或融合，形成新的主体、力量或结果。 |
| 环绕 | 对象围绕中心运动，改变彼此距离、秩序或从属关系；与摄影机环绕分别设计。 |
| 传递 | 物件、能量、信息或主动权从一个主体交给另一个，交接改变后续行动。 |
| 变形 | 形状、身体或结构连续改变，保留必要辨识线索，让转变过程本身承担看点。 |
| 扫描 | 光束、遮罩或边界扫过对象，逐区揭露隐藏内容或改变状态。 |
| 堆叠 | 对象或层次不断积累、压缩、重排或坍塌，发展负担、密度与规模。 |
| 流动 | 人物、物件或信号沿路径穿过空间或系统，在途中发生分流、受阻或转化。 |
| 破坏 | 已有结构、边界或秩序裂开、弯折、泄漏或重组，后果继续影响场面。 |
| 摄影 | 推拉、横移、环绕、视差或取景变化，逐步改变观众获得的信息与空间感。 |
| 材质 | 表面的纹理、透明度、反光或软硬状态变化，并通过运动或响应显现差异。 |

## 方式组合

按本片需要选择主导方式与辅助方式，使它们共同推进观看回报，不规定数量。需要通过重复发展意义时，使用[动作重复与变奏](#action-variation)；需要跨段追踪同一对象时，使用[转场中的持续追踪对象](editing-and-continuity.md#transition-tracking)。例如，传递可以与占位配合改变人物关系，流动可以与分支配合展开规模，变形可以与材质变化配合形成转化过程。

<a id="anti-ppt"></a>

## 反PPT检查

作品方案形成后，检查：

1. 主要段落是否只有人物或物件进入、摆好、停留、退出，进入之后缺少值得观看的发展？
2. 是否主要靠台词、字幕或解释交代变化，画面只提供相应的姿势与结果图？
3. 是否反复使用相同布局和同类表情，换了人物或背景，观看过程却没有发展？
4. 切镜是否不断重置人物、物件和空间，丢失原本可以持续追踪的行动与关系？
5. 摄影机、光效和装饰是否一直在动，但它们既没有展开事件，也没有带来新的信息、体感或情绪？

上述现象用于定位疑点，不直接判定失败。结合本片已选的风格与观看目标，检查持续期间具体产生了什么作用：行动是否改变局面，表演是否发展关系，重复是否改变意义，停留是否积累期待，声画是否带来新的感受。缺少具体作用时，先判断是否需要该段：需要则重做，否则删去；不以动作和效果数量判断改善，也不以导演名字或风格标签替代具体依据。

已有成片时，按[共用查看方式](../reference-videos.md#查看方式)核验相关区间。

对白与重逢场面尤其核对：角色站定后，当前取景是否能读清所依赖的反应，等待中有何新进展。固定双人中景若把细微表情缩小、遮住或持续压成侧脸，应在触发点换取景、靠近或改变调度；修复要明确新看见的反应与行动，不能只加全程漂移，也不把“少切镜”当作连续表演成立的证据。

<a id="rhythm"></a>

## 整片节奏

按主要动作、台词与反应的实际顺序估算时间。并行内容共用时间，先后动作保留启动、接触和恢复的过程；过渡、文字和结尾同样占时。超载时按下文重排主次，不靠把一切加速或删掉回报解决。

先围绕最值得看的过程和回报分配时间，再决定铺垫、过渡与余味需要多少。胜负、逃脱或反转若依赖环境、人物关系或物体状态的持续变化，应先确定何时开始、怎样发展，以及什么可见结果足以确认完成，为其分配时间后再安排前段；不能仅写成所有动作之后的一句结尾，也不能用静态参考图中的线索代替动态兑现。持续动作应维持或发展观看价值，物体仍在运动不等于过程仍有吸引力。某项自选强化放不下时，比较其收益与挤掉的体验，再选择放弃该强化、压缩重复、并行动作、省略可推知的过渡或重排整片，不把既有时间轴当成硬约束。

需要在峰值集中注意力或提高密度时，可用短特写、快速景别变化或成组短镜，随后用能看清结果的镜头承接；持续表演已经形成更强张力时，不为套用结构将其打断。需要用事件间隔组织期待时，可让重复事件逐渐缩短间隔，或让等待与短击交替并改变下一次的长短；主题多次返回也可改变强度、尺度或持续时间。按本片目的选择，不固定秒数或要求逐次增强。

例如，前冲途中插入约0.2秒的蹬地特写，再接回同一次前冲，脚步声连续，让瞬间细节加强动作力度。

较长段落通过动作、关系、空间或声画的实际发展维持分量，短段落可完成决定性的反应或揭示。取物、行走、变化前后的过渡不必全部顺序演完；保留理解因果与获得感受所需的证据，省略可推知的部分。持续演唱、仪式或长镜头已有累积效果时保留，不按固定切镜频率或反转数量判断节奏。

<a id="action-variation"></a>

## 动作重复与变奏

```text
〈人物〉第一次做出〈可辨认的动作〉，得到〈回应或结果〉。到〈后续时机〉，同一动作以〈保留的节奏、姿态或构图〉再次出现，其中〈人物、对象、动作完成方式或回应〉发生变化，使观众重新理解〈关系或处境〉，停在〈新的结果〉。
```

### 示例

```text
第一次他伸手替对方挡雨，对方继续低头走；再次伸手时，对方握住他的手，把伞移到两人中间。两次动作从相似的位置进入画面，最后两只手一起握住伞柄。
```
