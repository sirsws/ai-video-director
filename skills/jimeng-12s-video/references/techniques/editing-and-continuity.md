# 剪辑与跨镜连续

按[方法调用与复用规则](../creative.md#method-use)读取本片相关小节，已有充分决定直接沿用；据此决定切镜或连续观察及其衔接。

<a id="editing"></a>

## 剪辑、覆盖与观看方向

按信息和行动需要决定镜头数，不把时间分段自动当作切镜。希望观众连续跟随整个表演时，可用同一镜头内的阶段、调度和注意交接组织；需要比较不同视点、强调反应或跳过可推知过程时，可切到另一构图，动作仍可通过匹配衔接保持连续；快速蒙太奇用有区别的短画面集中信息，同时为关键行动、对白和结果留下所需时间。一个镜头能完成连续变化时不为凑镜次拆开；关键关系无法在同一取景读清时，选择重新调度、分阶段揭示或明确切镜。时间容量按[整片节奏](process-and-rhythm.md#rhythm)核对，不用固定镜头数或单镜秒数代替。

独立片段组成蒙太奇时，先确定共同主题或需要维持或改变的感受，再判断各段承担累积、对照、推进还是停顿，据此取舍排序并安排首尾任务；以动作、形态、颜色、声音或信息建立联系。可以柔和流转，也可以硬切卡点，不因并置就虚构原素材的连续因果。

每个切点交代 **为什么此刻切、从什么画面切到什么画面、动作和声音怎样承接**。可在动作中匹配衔接、切到反应、先给声音再见声源，或借明显空间线索建立新位置。涉及左右关系时保持观看侧；需要越过关系轴线时，用可见的摄影机经过、主体移动或新的建立画面让观众重新定位，不让角色在正反打中无故交换位置。

检查是否把主体验切没了：关键交接、碰撞、变形过程若需要被看见，不能在发生前切走、发生后只给结果。反过来，观众已能理解的准备不必重复拍。需要多个景别时，先列每镜头新增的信息，再决定取景与时长，避免重复覆盖却没有推进。

要求切镜却生成了连续运镜时，先核对正文是否明确切点及两幅不同构图；要求一镜到底却出现跳切时，检查是否把过程阶段写成独立镜次，或省略了连续路径。连续时间中，同一主体的相邻镜头若像无意跳动，核对景别或观察角度是否太接近；按观看目的拉开区别、保留单镜，或明确采用有意跳切。先修实际存在的表达冲突，不把镜头标签或时间戳当成必然执行的控制语法。

<a id="shot-continuity"></a>

## 跨镜状态

把连续性记录写在本片的镜头条目中，全局不变项只定义一次，各镜头写状态变化：

| 维度 | 要承接的具体状态 |
| --- | --- |
| 人物 | 身份、发型、服装、身体朝向、表演阶段；谁刚知道或做完什么。 |
| 道具／产品 | 谁的哪只手持有、朝向、位置、开合或损坏状态、结构、材质与标识。 |
| 空间 | 人物与目标相对位置、门窗或地标、可用路径、前后景与遮挡。 |
| 方向与视线 | 场景方向、画面运动方向、人物看向谁或什么，反打是否对应。 |
| 光色与摄影 | 时间、光源方向、关键明暗与色彩，透视、机位高度或运动风格哪些延续。 |
| 行动与声音 | 上镜动作进行到哪一步，是否仍运动；对白、音乐、环境声或动作声是否跨切镜。 |

上镜结束与下镜开始必须相容；有意跳时、换地、改变状态时明确发生在何处，以什么线索让观众理解。不能靠“无缝”“连续”两个词代替实际承接。

<a id="match-action"></a>

## 动作匹配

```text
连续动作：上一镜进行到〈动作阶段〉时切换镜头，下一镜接住〈方向、姿态和节奏〉，继续完成〈动作〉。

跨越时空：上一镜的〈动作或构图〉切到〈另一时间或地点〉中相似的〈动作或构图〉，〈环境或人物状态〉显露变化。
```

<a id="transition-tracking"></a>

## 转场中的持续追踪对象

同一地点跨越年代时，可保留可辨认的空间标志，通过陈设、材质与维护状态的变化表达时间经过，光线辅助情绪变化。需要后态参考输入时，按[结构变化与状态连续性](spacetime-effects.md#structural-change)核对。

```text
〈起始画面〉中的〈物件、轮廓或色块〉作为持续关注对象。通过〈切镜或连续变化〉进入〈目标画面〉时，保持它的〈可辨特征、画幅位置、比例或运动方向〉，由〈周围变化及主体响应〉显露时空或形态的转换，落在〈结束关系〉。
```

### 示例

```text
红伞始终位于画面中心、占比近似稳定，伞后拥挤车站逐渐转为雪地；积雪落上伞沿，人物的手仍握住同一处伞柄。
```
