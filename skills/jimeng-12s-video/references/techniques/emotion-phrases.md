# 情绪短句

仅在需要具体表演措辞时查用，按人物意图和当前景别改写，不作为固定配方。

<a id="emotion-phrases"></a>

## 情绪短句

<a id="sadness"></a>

### 哀：悲伤、委屈、崩溃

```text
哀伤泛红：眼眶微红，泪光积在下眼睑，眉头内收，嘴角下垂，克制悲伤。
空洞麻木：目光凝滞、没有明确落点，眼皮沉重，面部放松，嘴角平直，疲惫麻木。
泪水滑落：泪水从眼角滑落，鼻尖微红，视线低垂，嘴角下坠，安静地哭。
隐忍不哭：眼眶泛红，眉头微皱，下巴绷紧，快哭却努力忍住。
低声啜泣：手轻捂嘴，眼神低垂，肩膀微颤，低声啜泣。
绝望闭眼：双眼紧闭，眉头皱起，唇部颤动，下巴收紧，痛苦而绝望。
崩溃大哭：双眼紧闭，泪水涌出，眉毛内收，张嘴哭喊，面部用力扭曲。
默默流泪：表情平静，泪水滑落，嘴唇自然闭合，眉眼无光，无力表达悲伤。
委屈撇嘴：下唇前顶，嘴角下撇，眉头微皱，眼眶湿润，目光带着控诉。
触景生情：看见〈勾起回忆的对象〉，目光在它上面停住，嘴角微颤，再缓缓望向远处。

```

<a id="surprise-fear"></a>

### 惊：震惊、恐惧、害怕

```text
惊讶停顿：双眼睁大，直视前方，嘴微张，呼吸短暂停住；瞳孔变化仅在明确需要极近特写且可辨时考虑。
震惊僵住／瞳孔地震：眼睛睁大到僵硬，嘴唇微张却说不出话，眉毛抬起，慌乱紧绷。
惊恐后退：身体后缩，肩膀抬起，双手挡在胸前，眼神警惕，嘴巴微张。
恐惧僵住：目光固定，张嘴却发不出声，眉毛抬高内收，脖颈紧绷，身体僵住。
难以置信：睁眼扬眉，头微后仰，嘴轻张，带着惊讶与迟疑确认眼前现实。
怀疑警惕：微眯眼侧视，一边挑眉、一边压眉，抿住嘴唇，头略后退，防备不信任。
心虚躲闪：视线向旁边或下方躲开，嘴角轻抽、唇微抿，肩膀收紧，慌张地掩饰。
惊吓后怕：手按胸口，呼吸像刚恢复，眼神仍惊慌，面部慢慢放松却残留恐惧。
毛骨悚然：眼睛半睁，眉头紧皱，不安地侧视，嘴唇微张，像察觉危险靠近。
绝望失神：可沿用“哀”类空洞麻木的身体与面部基调，按此前遭遇调整余下反应。

```

<a id="anger"></a>

### 怒：愤怒、憋屈、爆发

```text
眉头紧锁：眉毛下压并紧拢，眉间起褶，抿紧嘴唇、嘴角下压，克制生气。
阴沉脸：眼神冷漠下沉，嘴角平直无笑意，阴沉地隐忍不发。
咬牙切齿：牙关紧咬，下颌绷紧，凶狠瞪眼，鼻翼微张，强忍怒火。
妒忌不服：看向〈对方得到的待遇或物件〉，单侧嘴角拉紧，眯眼审视，再看向对方；具体关系承载嫉妒读法。
冷眼相视：冰冷直视，眼皮下压，面部没有多余表情，冷硬疏离。
轻蔑不屑：单侧嘴角上扬，斜眼挑眉，抬起下巴，高傲而讽刺。
憋屈忍怒：紧紧抿唇、垂眼，手部攥紧，皱眉隐忍，把委屈和怒气憋住。
暴怒前兆：眉间紧绷，眉毛压低，眼神凶狠，嘴唇微颤，肌肉绷紧，即将爆发。
爆发怒吼：嘴大幅张开，眉间收紧，双眼睁大，面部肌肉拉扯，怒吼宣泄。
生闷气：嘴巴微嘟，脸扭向一侧，肩膀收紧，别扭而不满。

```

<a id="smiles"></a>

### 喜与笑容：开心、甜蜜、暗爽、无奈

```text
自然微笑：嘴角轻扬，眼睛柔和弯起，脸颊略提，放松亲切，笑意自然克制。
俏皮眨眼：一只眼轻闭，另一只眼带笑，嘴角微翘，头轻偏，灵动调皮。
灿烂大笑：张嘴露齿，眼睛因笑意眯起，脸颊抬高，头可微后仰，开朗无防备。
坏笑／邪笑：一侧嘴角轻挑，眼睛半眯，眉尾略扬，得意玩味，像在调侃。
甜蜜对视：专注地看着对方，眼底带温柔笑意，脸颊微红，安静甜蜜。
天真相信：目光直接看向说话者，嘴角轻扬，点头后毫不迟疑地照对方的话行动。
暗爽得意：单侧嘴角轻扬，眼睛微眯，视线偏向一侧，得意但不张扬。
宠溺笑：嘴角温柔上扬，眼神柔软带笑，眉眼放松，头轻倾，包容而心软。
羞涩低头：嘴角抿出笑意，视线向下、不敢对视，脸颊微红，轻轻低头。
苦笑／无奈笑：嘴角勉强上翘，眼里没有真正的笑意，眉头轻皱，疲惫而无奈。
```
