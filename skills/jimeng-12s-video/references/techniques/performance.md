# 人物表演

按[方法调用与复用规则](../creative.md#method-use)读取本片相关小节，已有充分决定直接沿用；据此按本片人物任务选择演法。

按创意已定的叙事或非叙事任务选择演法，再依据景别判断观众能否读到。叙事从目标、策略和回应推导；非叙事从身体任务、节奏、空间与感官过程推导，不强加隐瞒或冲突。局部情绪写法用于具体表演，不能替代完整行为。

选择最能承担本段变化的行为，说明它何时开始、维持、失效或转为下一步。表演尺度由本片风格决定：写实可依靠细微停顿，外放表演可用全身动作、节奏与空间，冷面表演可让认真执行与荒谬处境相撞。动作细节必须与景别匹配，不能在全景里依靠微小眼神完成关键转折。

<a id="emotion-expression"></a>

## 情绪表达

```text
1. 情绪主词＋五官局部＋肌肉细节
例：悲伤＋眼眶泛红＋眉头微蹙＋嘴角下压

2. 情绪主词＋呼吸／身体反应
例：崩溃＋肩膀颤抖＋呼吸急促＋双手握拳

3. 情绪主词＋视线方向
例：暗恋＋视线下移＋睫毛微颤＋脸颊泛红

4. 双情绪叠加
例：又气又委屈，例如：眼眶含泪＋眉头紧锁＋嘴唇紧抿

```

人物态度要结合当前画面中的视线、姿态、距离、接触、发声与回应判断，不要求每项都有设计。结合具体镜头判断行为组合是否支持预期的人物关系；出现明显偏差时，优先调整造成偏差的行为及其衔接，不能只追加性格或情绪标签。

<a id="continuous-performance"></a>

## 连续表演

叙事表演从已定目标与策略出发；人物为何这样做尚不清楚时，先用[人物驱动力](#character-drive)补足当下原因。把“情绪”改成“正在做的事”：想被相信、对方不信，于是稳住声音并迎上对方视线。关键节点写 **触发 → 可演行为 → 对方／环境回应 → 行为改变或停止**；潜台词需要表里差距时，用言语与身体、物件或距离的差异显出，例如嘴上答应却握紧杯子。没有这种差距的场景不硬造隐瞒。

```text
触发与当下意图 → 关键反应的变化 → 说话／行动 → 结束状态
```

叙事中的连续变化围绕人物正在争取的结果展开：情绪可以妨碍行动，人物也可以继续坚持、补救或改变选择，不必只让同一种情绪越来越强。需要掩饰情绪时，区分真实感受与想让对方看见的表现，选择压住、短暂流露或重新收回的关键变化；是否露出破绽、何时发生，由处境与对方的反应决定。

当关键观看效果依赖人物态度转变时，建立可辨认的前后差别，并明确转变的触发。选择能让观众读清转变的表演与镜头安排：动作、切镜或运镜若会掩盖关键反应，应错开；能够共同强化转变时，可以同步。当剧情依赖双方相互影响时，写清一方的言行怎样改变另一方的回应；若不回应本身承担表达，也应让观众能够读到。停顿或等待承担关键回应时，核对观众凭什么将它读为对触发事件的反应；依据可来自此前活动、注意对象、持续时间或声音变化，不必放大身体动作。

### 示例：失望却仍想挽留

```text
听见对方告别，他抬眼想开口；见对方转身，嘴唇抿住，
呼出一口气，低声说“滚”。话音落下，目光仍停在对方身上。
```

### 示例：愤怒并明确驱离

```text
对方再次伸手靠近，他收紧下颌，抬手截住，
盯着对方短促地说“滚”。说完侧身让出门口，等对方离开。
```

### 示例：想装作相信，却忍不住笑

```text
听见对方一本正经地解释，她抿住嘴，想装作相信；
抬眼看他时，嘴角还是漏出一点笑。停半拍，轻声问“是吗？”，
说完仍看着他，等他继续编。
```

### 示例：触物记忆打断准备好的回答

当记忆与表里变化承担本片的人物读法时，可让接触打断说辞，由动作透露声音未直说的依恋：

```text
受访工匠正在讲述准备好的答案，手触到旧工具的磨痕后话头中断，
拇指沿熟悉位置摩挲；双手停稳后，继续平实地说话。
```

这里的过程是受访者的准备回答被触觉打断，声线可以始终平实；清楚展示工具操作是另一种观看任务。

<a id="character-drive"></a>

## 人物为什么这样做

人物的行动或转变缺少依据时，从已知处境找出真正影响本段选择的关系：他此刻想得到什么，又舍不得损失什么；习惯用什么办法，这个办法带来什么结果，代价影响本段选择时再看它损害了什么；哪个事实或对方的回应会使他坚持、换办法或退回去。只补本段需要的原因，不为短片另写完整小传；人物也可以不变，不必经历成长或受苦。

“骄傲”本身不能决定演法。例如剑客拒绝同伴递伞，仍抱着小猫冒雨走；小猫缩进湿透的衣襟，他才接伞，却把伞面先挪向小猫。想独自撑住、又不肯让小猫受冻，使拒绝与接受来自同一个人。取景要看见递伞、护猫与伞面的移动，雨声和衣料摩擦让变化发生在持续行走中，不必停下解释心理。此为原创方法示例。

若人物突然换办法，核对变化前他实际知道了什么、重视什么；若由误判或自欺推动，让对应的言行提供依据。双方互动决定转变时，也考虑对方的目的和回应，不能只为配合主角转变而让步。把补出的原因落实到原方案的动作、台词和声画，心理说明不直接堆进提示词；下一步仍用[连续表演](#continuous-performance)组织过程。

本节适配自 Drama 固定版的[行动模型 §4](https://github.com/zenstory-ai/drama-skills/blob/7e6336047ddb3c6344b3c3966a81ad8008d23c11/skills/short-drama-develop/references/story-craft.md)与[驱动力及策略变化 §3—4](https://github.com/zenstory-ai/drama-skills/blob/7e6336047ddb3c6344b3c3966a81ad8008d23c11/skills/short-drama-develop/references/serial-character-and-memory.md)；只取影响本段行动的因果，不搬入连载角色档案。

<a id="non-narrative-performance"></a>

## 身体任务与专业表演

身体任务与戏剧目标分别设计：舞蹈、歌唱或其他专业表演，无论是否承担叙事，都要组织其段落与变化。纯欣赏时不另造冲突；叙事中的试探、掩饰或关系变化落实进同一段表演，不用表情反应替掉身体任务。观察与功能展示按实际活动的速度、幅度、空间关系及可见或可听的终点组织。

舞蹈承担观看回报时，先写出可连续表演的舞句：脚步与重心怎样发起，肩臂、手腕或躯干怎样接续，幅度、方向和停顿怎样形成节奏；只选本段起作用的部位，不逐项填满。写清舞句的重复、变奏或双方回应，不能用舞种、拍数或道具交接代替舞蹈本身。决定辨识度与关系的动作写入正文，其余衔接才允许自然变化；不把“一段一个动作”当作上限。完整例子见[双人踏舞与手杖交换](../examples.md#dance-example)。

歌唱的乐句与发声按[歌唱与节奏](music-and-sound.md#song)设计，武打的交锋与应对按[行动与空间调度](action-and-staging.md#action-scene)设计。各类专业表演都需与人物情绪、空间和镜头配合，固定歌词、动作或节拍直接写明。

<a id="character-design"></a>

## 人物造型与起始状态

主要角色面部可辨时，明确符合当前处境的起始表情或表演基调；人物素材自带的表情不自动代表角色当下状态。用当前景别能读到的简短正向描述表达，符合本片需要时也可沿用原表情。人物态度需要变化时，只保留会影响人物读法且能被当前画面承载的节点。

在保留已锁定的身份与造型要求的前提下，对影响观看效果的未定部分，主动设计服务角色读法与行动的体型、发型、妆面、服装、轮廓与材质，可呼应其身份，也可用有意反差参与表达。造型承担主要吸引力时，判断辨识度主要来自轮廓与比例、部件结构与连接，还是材质与装饰，据此组织整体设计。以人物吸引力为主要观看回报时，在关键景别中同时考虑身体线条、衣装贴合、姿态、表情与用光，先把吸引力落实到具体画面，再判断互动或剧情能增加什么体验。普通 AI 的独立剧情角色须在拍摄设计中形成具体且彼此可辨的人物设定，不能到编译时只用职业与制服标签填充；独立角色与群演的描述粒度见[角色定义规则](../prompt-compiler.md#视频提示词编译)。造型既要支持关键动作和人物气质，也要让核心人物在预定景别、运动速度及环境中容易辨认。

体型按本片角色目标或用户明确要求落实，区分身体比例、肌肉形态与衣服活动余量；修正偏瘦或偏胖时定位需要改变的部位，不把增减衣物体积当作整体体型的替代。三视图与视频文字须支持同一个目标，项目提供个人偏好时再沿用，不默认某种身材。

<a id="group-performance"></a>

## 群体表演的差异

多人同场先分清当下的 **主要行动、有效回应与背景持续活动**。主要行动可以是一个人的决定，也可以是双人交换、群舞或多人共同完成的任务。用位置、时机、幅度、视线、景别或焦点安排注意力，重点转移时给出交接依据；其他人继续做与处境相符的事，避免所有人同时用强动作争抢或僵立等待。多人共同表演须写清同步、错拍、轮替或接力怎样形成整体。

群体共同完成一项任务时，可通过入拍时机、熟练程度、动作幅度和注意对象的差异，表现自然感、人物关系或喜剧。根据观看重点，选择整体节奏、局部成员或两者配合来表达群体变化，并核对所选线索在当前取景中是否可读；细节不足以承担关键回应时，调整表演、站位、取景或信息先后，不预设必须突出个别人或另加特写。

需要某人带动或接管表演时，定清他向谁发出动作、歌声或视线，以及回应怎样改变节奏、空间或关注：对方可接唱、错拍后跟入、让出行进线或转向他，他也可用拒绝同步改变共同节奏。面向观众的表演可用直视、靠近或离开摄影机改变距离。按本片选一条可见或可听的发起—回应—变化，不用居中、推近或旁人围观自行证明主导权；等权群舞不必安排一人接管。

```text
孩子们跳同一段舞：一人认真跟拍，一人慢半拍并偷看同伴，另一人向家长挥手后赶着接回动作。
```

<a id="exaggerated-performance"></a>

## 夸张表演

表演幅度与画面写实程度分别选择。按人物意图与作品调性，选择放大关键姿态、改变身体形态，或用图形与环境外显心理；这些手段可单用或组合。形变时明确变化部位与仍需保持可辨认的特征，不把身份一致写成所有比例都不许变化。

```text
〈触发〉使人物〈反应或行动〉，〈承载其意图的姿态、部位或画面元素〉
以〈形态、幅度与时机〉变化，接续〈后续行动或停留状态〉。
```

用变化速度、停留或余动组织[节奏](process-and-rhythm.md#rhythm)，不固定为逐步增强、爆发后定格。夸张可以继续参与人物行动，也可停在鲜明状态；背景、形变与声音不必同时加强。效果需要与现场发生联系时，查用[特效与实景联动](spacetime-effects.md#effect-interaction)；主观图形不必强加物理反馈。
