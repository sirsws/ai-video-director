# 作品创作：内容与声画一起形成

把用户的起点发展成观众实际能经历的过程。内容、表演、空间、摄影、光色、节奏和声音共同设计；镜头可以产生笑点、揭示和体验，本身就是作品的一部分。

## 从当前起点继续

| 已有内容 | 本次实际要做的工作 |
| --- | --- |
| 一句话、题材或“想做爆款” | 找到值得看的具体机制与场面，发展少量有实质差异的构想。每个包含主要过程、关键拍法和回报。 |
| 初步故事或选定方向 | 保留已定事件与意图，补触发、行动、信息、表现和声画安排；不重新换题或凑候选。 |
| 已有拍法 | 从观察位置、路径和时机发展内容，补足“镜头经过时究竟发生什么”；不把拍法当可随意删的装饰。 |
| 已有提示词 | 理解现有声画过程，按本次要求深化；本次为局部修改时遵循[局部返修](production-and-delivery.md#local-revision)。 |
| 局部反馈 | 按[局部返修](production-and-delivery.md#local-revision)处理修改目标及必要衔接。 |

已有用户要求、项目约定、当前 Brief 直接使用，不以问卷重新收集。用户举例时辨明其要借的体验，不能把例子的服装、道具或时代擅自变成所有候选的限制。只有真的需要改变已定要求，或缺少会改变方向的信息时才提问。

## 方法进入构思

新作品在形成或深化构想时，查看[25类方法入口](methods.md)，读取本次能改变具体决定的相关正文。既有读取充分且条件未变就沿用；局部修改只补相应方法。索引摘要不能代替方法正文，也不要求通读整库。

先按主要观看体验选择方法，再按需要组合场面、主体、媒介或输入方法。例如“修仙喜剧”可把认真执行的荒谬与尺度揭示结合；“黏土赛车”可把车辆运动与定格节奏结合。只借所需机制，保留用户的事件和明确拒绝项；无贴切模板就根据活动、观察位置、变化与声音自行设计。

方法要实际影响一项选择：笑点怎样发生、动作怎样连续、相机为何移动、声部在哪一下进入。不能只报模板名，也不因为模板有反转、台词或定格结尾就强加给本片。需要具体原稿或用户指定参照时，按[参考选择与改编](reference-adaptation.md)读取相关底稿；项目提供参考库时沿用其入口。已有充分原稿可直接发展其成套拍法。

具体技法在设计相应部分时，从[技法索引](techniques/INDEX.md)定向读取：攻防读动作，歌舞读表演和声音，遮挡揭示读注意与空间，二维读图层与动画。需要比较整套摄影、光色、表演处理时，读[拍摄处理](shooting-treatment.md)。实际需要的正文输出截断时补读，不能用“已考虑”代替决定。

## 用同一方案共同发展

先找观众真正值得经历的过程，再同时解决相互依赖的决定。下面是方案需要解决的问题，不是每片必须填满的栏目：

- **内容与回报**：从哪里进入，发生什么活动、行动或变化，何处最值得看或持续值得看，结束时观众得到什么。叙事的因果、非叙事的活动、功能展示的证据各用适合的方法，不强行加入冲突或隐情。
- **表演与空间**：谁对什么做什么，必要的准备、接触、回应和后态；地形、道具、服装与身体怎样参与。尺度、速度、夸张和外放程度服务本片，不默认微动作或克制。
- **观看位置与信息**：选择适合本片的[画幅与构图](techniques/camera-foundations.md#framing)，安排观众先看见谁、何时知道新信息；取景怎样容纳关键身体和物件；相机起点、经过、终点或保持关系。人物移动与相机运动分开，必要时安排切镜、遮挡和焦点交接。
- **光色与媒介**：关键对象怎样从环境中辨认；光源、明暗、色彩、材质和成像怎样支持观看过程。采用有意混合媒介时，说明各自作用范围。
- **时间与声音**：哪些同时发生、哪些必须先后，主要过程占据什么段落，反应和回报有多少可读时间；对白/演唱、配乐、环境声与动作声何时出现、让位和结束。声音可以触发行动、揭示画外事件或承担反差。
- **参考与实现**：哪些身份、造型、空间或状态需要具体输入，哪些可由文字表达；按[图片用途与取舍](reference-images.md#reference-selection)选择，图上存在的姿势不自动锁住整段动作。

写成一条连续声画过程、按镜头或按时段展开均可。全片共同项写一次，段落只写变化；不规定镜头数、逐秒动作或器材参数。具体安排须足以让生成准备直接落实，不能把关键拍法全留到编译时再想。

例如“观众先看到拖在后面的剑鞘，修士拔剑落空才发现”，要同时安排后景可见、拖行路径、人物注意和拔空声；仅写“最后反转”不能完成这项决定。“镜头绕行发现巨物”则需让路线真正改变可见信息，不能用人物自转替代。

动作、机位、取景和声音相互影响时一起解决：近景会放大表情却可能切掉手部交接，浅景深会突出前景却可能藏掉背景笑点。修关系时保住核心过程；无需把所有手段都弱化。需要场面、风格或开始/结束的具体选择，查[拍摄处理](shooting-treatment.md)。

<a id="spatial-previs"></a>

若关键路径、朝向、遮挡或摄影关系尚未确定，且几何预演能回答会改变拍法的问题，按[空间预演](blender-previs.md)验证并查看结果。已有充分空间证据可直接采用；题材复杂或动作多本身不等于必须预演。造型、表情、对白等非几何问题用对应方法判断。预演不能证明生成动态、表演或听感成功；后续素材改变使证据失效时，只复核受影响关系。

## 候选与深化的完成条件

全新方向的候选应让用户看懂：具体经历什么、怎么拍到关键过程、主要回报在哪里。用户以传播为目标时，再说明重播、分享、评论或参与的具体动机；这是有内容依据的判断，不能虚构效果。不为凑固定数量给换皮方向；少量候选之间要在事件机制或观看体验上有实质差异。

推荐前，假定按描述完整实现，指出它相对常规处理多给了观众什么具体体验，并核对是否达到本次目标与表达强度。只有“画面美、很燃、有共鸣”等判断，或只是本批最好，却没有值得看的具体差异，就继续发展或淘汰；安静观察也可凭光影、声音和注意变化成立。没有值得推荐的方向时，改变构思机制再探索，不以降低标准凑数；没有新依据或有价值的新尝试时说明决定性缺口并停止。这个判断针对作品本身，不能用未验证的生成难度否决有价值的构想。

新作选定方向后，继续深化同一方案。用户明确指定的安排，以及删换后会破坏已选核心体验的安排，需要保留；深化中的初稿景别不自动锁定。有实质改法时说明原作用由什么新安排承接。只保留故事梗概而丢掉连续奔跑、环绕揭示或完整乐句，不能算保留了体验。

完成前按方案本身检查：假如照此实现，是否具体兑现本次要求？主要过程有无必要的中间状态和回报？摄影能否看见它、声音是否有实际安排？只有形容词、结果摆拍或解释里才存在的意义，返回相关方法补设计；不靠增加风险声明通过。

安排具体且相容，只是身份保持、运动自然度或口型尚未生成验证时，属于执行未知。不要以消除未知为目标删掉作品想看的过程。无已知缺口则进入[生成准备与交付](production-and-delivery.md)；已选方向不再等待一次独立导演确认。
