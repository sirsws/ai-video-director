# 悬疑与恐怖：安排异常、知识与逼近

观众想确认发生了什么，或害怕已经知道的事将怎样逼近时使用。悬疑可以有解释与解决，恐怖也可以持续观察一个不安状态；不强制丧尸、伤害、反转或留尾钩子。组合权限见[方法使用](../creative.md#method-use)。

## 先决定谁知道多少

观众与人物共同发现异常，产生的是探查；观众先知道危险、人物仍照常行动，产生的是等待；人物先看见而观众只见反应，产生的是追问。选择其中符合本片的关系，再决定画面和声音何时提供证据。故意藏信息要保留推理入口，不能只靠剪掉关键动作制造无从理解的谜面。

| 要看的过程 | 可执行构造 | 适用的声画安排 |
| --- | --- | --- |
| 普通事物变得不对 | 先使一个状态可辨，再让位置、数量、影子、声源或回应出现差异。 | 保持可比较锚点，换视点时仍能认出同一物件；声音也可先建立正常模式。 |
| 解释逐步失效 | 人物用常识验证异常，验证结果排除一种解释，迫使下一次行动改变。 | 拍到验证动作和结果，别用人物一句“不是风”代替门窗或声源证据。 |
| 危险逼近 | 观众能辨认安全处、来路与距离；威胁通过实际空间或声响缩短间隔。 | 用路径、遮挡、脚步远近、光区变化组织逼近；相机可跟随、后退或主动寻找。 |
| 相似事件变奏 | 重复一段已知路径或动作，某个环节提前、迟到、消失或换对象。 | 让观众认得前一次规则；第二次变化要进入镜头或声音，不只写“更加诡异”。 |
| 安全解释后的残留 | 局部问题看似解决，但一个仍在发生的细节证明解释不完整。 | 留下能够辨认的残留，避免结尾突然引入从未有线索的新怪物替代原悬念。 |

这些可以单独成立。若作品是氛围观察，没有调查者也没关系：水面倒影迟于岸边树枝摆动，持续的不一致本身就是体验，不必添加人物身世。

## 空间与声音共同透露证据

画外声要有方向、距离和可辨变化。例如右后方的脚步在角色停步后仍继续靠近，摄影随后转过去；如果声音本应来自门后，开门后为何变弱或消失要有本片安排。音量突然抬高只是一种冲击，不应替代异常过程。

遮挡的用处是控制“何时看见”，不是默认把整个危险藏到片外。镜头绕过门边能揭空间，拉焦能交出背景信息，光扫过能让反复出现的轮廓可辨。具体方法读[注意力与揭示](../techniques/staging-and-reveal.md#attention)、[画外行动与画内后果](../techniques/music-and-sound.md#offscreen-consequence)。

有时需要反应先行，有时让角色不察觉更有力。表演依据他此刻知道的事；不在他还没听到或看到时先做恐惧表情。静默也要说明哪些声音停了、留下什么，不把漏写音轨当设计。

## 原创示例：楼梯里的多一步

夜班保洁拖着装有拖把的水桶下楼。低位镜头在楼梯侧面跟着他的脚和桶沿移动，脚步与桶轮每下一级配成一组。到平台他停下，身后却又响了一次同样的轮声；桶里的水从平静变成朝楼上方向聚起一道细波。他提起桶继续走，轮声仍在楼上独自继续，镜头向上摇到空楼梯，而水波还在指向那个方向。

异常来自“属于水桶的声音离开了水桶”，声音、物件和摄影共同提供证据。无需增加凶手、血迹或台词。若是无对白环境片，可停在空楼梯与持续轮声；若用户希望解谜，继续的内容应回应此声源，而非另起一只怪物。这是未生成的原创方法示例。

## 组合与失效定位

与[叙事对白](narrative-dialogue.md)组合时，异常应改变人物判断或行动；与[生活观察](observation-and-travel.md)组合时，摄影者的可信注意路径能支撑“拍到怪事”的感觉；与[时间变化](spectacle-and-change.md#time-control)组合时，明确哪些对象的时间不同，避免所有状态同时乱变。

如果看不出前后差异，先补比较基准；如果开头就把答案全部展示，重新安排参考图和信息时间；如果人物持续惊恐却没有新证据，补具体遭遇或停止无作用升级。镜头数量、黑暗程度、冲击声数量都不能代替这些决定。
