# 动作与速度：让运动改变局面

适用于打斗、追逐、体育、车辆与特技。先确定正在完成的身体/机械任务，或运动给观众的体验，再选择速度、力度与观看位置。幻想动作允许超现实，但承担主体验的接触、路线和状态仍要看得明白。组合遵循[方法使用](../creative.md#method-use)。

<a id="combat"></a>

## 对抗有应对，动作有后果

对打可按“发起 → 对方回应 → 位置/机会改变 → 下一行动”形成链。一次进攻的方向、目标部位或空间目的越具体，防守才有东西可回应；闪避后应到达能接下一招的位置，不能每次回到起手pose。

编排密集群战时，将换目标接进收招、穿步和落脚：上一人被打退，下一人已截路或追来。需要贴近参考密度时，按相同口径比较攻击与间隔，敌人数不等于出招数。

分别写清人物、武器和摄影机各自怎样运动，再围绕同一段攻防安排它们的时机关系。谁发力，哪里接触或擦过，身体怎样失衡、卸力、恢复；武器由谁哪只手持有、何时换手或落地。场面紧张可以来自近身距离、追上/甩开、地形改变办法，而非每一击都加爆炸。

以追打、穿行为主要回报时，把“重新占位”落实为经过的地标、新落点与下一次接战的位置，避免招式接上了，人物仍反复回到同一点。摄影跟随这条人物路线，让距离和遮挡的变化可见。

以交锋为主的段落，位置变化由攻防或战术需要带出；跨场换镜可承接正在进行的动作，省略不承担观看作用的中间行程。

例如长枪手封住桥面，短刀手借枪杆掠过时下蹲踏上桥栏，在对方回收枪杆之前越过身侧。先确定桥栏、枪尖和通过路线，再选侧跟、后撤或切换。镜头不必固定，但不能把真正越过防线的过程藏没。细节见[攻防与地形](../techniques/action-and-staging.md#action-scene)、[接触与衔接](../techniques/action-and-staging.md#continuity)。

用飞退撞物强化重击时，选景先看退路、碰撞距离与物件材质。按“击中身体→飞退撞物→受压破坏→碎物落地”承接，破坏程度与材质、尺度和来力相称，并留出下一次接战或落地的空间。

当武打需要鲜明的冲击或节奏感时，围绕逼近、发力、交锋、应对和余势，决定摄影何处加速或靠近、何处收稳、何处随闪避或错身转移。摄影变化要接住下一次行动，同时让关键交锋及其后果可读。节奏由连续攻防组织，也可与音乐配合。

可选写法示例（双人交锋）：

```text
斜侧全身取景，A在画面左、B在右，镜头保持在两人连线的同一侧。A向右踏步出拳，摄影机随A向右短距横移；B架开来拳时，摄影机收速稳住，保留交锋过程。B顺势向左进步反击，A向左撤步避让，摄影机随A向左回移；A撤步落稳时，镜头逐渐减速，仍让两人和落脚入画，接住B继续逼近的动作。
```

可选写法示例（群战追打与撞物；原创设计，未生成验证）：

```text
主角沿窄巷向木门进逼，短拳逼退正面者，侧身穿过来敌身侧的空档，回踢把追来者送向巷边空木箱。肩背撞裂薄板、箱片散落时，主角收腿落到更靠门处，下一人已从门边截来。摄影斜侧跟过箱角，起腿时略展开看清命中，随飞退带出撞箱，再跟回主角继续进逼的新位置。
```

<a id="sports"></a>

## 技巧需要被完整看见

体育和特技先找观众要看的技术节点：助跑、起跳、接触/支撑、空中变化、落地或继续滑行。按动作特点保留关键链，不是每项必须全部出现。跳跃若从半空开始，仍需让人读懂方向、身姿变化和落点；接续已有动作时从真实阶段开始，不重演准备。

力量通过身体和环境响应可见：脚掌压缩后蹬出，轮胎受压回弹，布料滞后，落地后重心继续前移。慢动作适合看接触或空中变化，正常速度适合体会连续技巧；变速要指向具体节点。明确旋转次数、步法或落点是用户要求时保留，不能因“模型可能算不准”自动删除。

表演与竞争不同。纯技巧展示可以没有对手；紧张比赛则让距离、机会或成绩在动作中改变。不要为每段体育追加人物创伤，也不要用“热血”替代动作路线。

<a id="vehicles"></a>

## 车辆与速度

先区分要看产品结构、驾驶操作、道路体感、竞逐还是变形。车辆身份需要外形与关键部件连续，骑手与坐姿、方向盘/车把、轮胎接地不能脱开；虚构悬浮或变形车辆按明确设定处理。

速度需要相对关系：路面纹理向后流，近处护栏快速掠过，远山较慢移动；相机与车同步前进时，可短暂落后、让另一物体被追过或切入前路显示进展。快速剪镜并不自动构成速度。

弯道交代入弯方向、车辆倾斜或车身侧移、路面边界及出弯去向。变形时说明哪些部件翻转、展开、滑动，运动如何继续；不能只是闪光后换一辆车。具体用[速度感](../techniques/action-and-staging.md#speed)、[部件重组](../techniques/spacetime-effects.md#component-reassembly)。

## 摄影也有路线

先确定希望观众追踪人、物、目标还是危险，再写摄影起止位置、运动方向、视点如何变化。跟拍能体会推进，领拍能看追来的威胁，侧面适合读接触与身体形态，环绕能显出对抗关系；没有一种是动作片默认唯一选择。

相机绕主体、主体自己旋转和变焦不是同一运动。快切与长镜均可成立，关键节点需要清楚的起因和后果；有意冲击重复、越轴或夸张变形要让观众重新辨认关系。技术见[相机相对运动](../techniques/camera-foundations.md#motion)、[剪辑与观看方向](../techniques/editing-and-continuity.md#editing)。

声音对应发力、接触和材质：喘气、衣料、脚下摩擦、碰撞余振、发动机升降。效果声可以夸张，但区分真实接触与擦身而过，别每次动作都配同一种轰响。

## 原创示例：风中滑板穿旗阵

滑手下坡加速，压低身体从两排布旗间穿过；侧前方相机并行，近处旗边快速掠过。前轮压上矮石沿，板身弹起，滑手收膝越过横躺的旗杆，在落地时深蹲吸收冲击，继续滑出旗阵；相机从侧面转到身后，露出向前展开的坡道。轮声先密后空，再以落地声接回，布旗声从两侧扫过。

动作乐趣来自速度建立、真实越过和落地继续，不是三个空中姿势。若改成黏土定格，保持动作链，去[动画媒介](../techniques/animation.md#stop-motion)选择姿势节奏；若改奇幻，改变重力规则也要保留观众要看的推进与落点。这是原创未生成示例。

失效时看具体断点：进攻无人回应、接触没发生却有撞击声、相机同步导致没有位移证据、落地后道具复位、最关键操作被切掉。先修空间、阶段、摄影或声音对应，不把整段改成“稳定展示”。武打摄影承担节奏回报时，核对摄影具体强化了哪次发力与应对，关键交锋和后续动作是否仍然读得清。
