# 叙事与对白：让行动改变观众的理解

适用于有事件因果、人物选择、关系变化或信息揭示的作品。已有故事就补其中尚未成立的行动和声画，不因有台词、人物或古装题材便强行增加隐情。调用与组合遵循[共同创作的方法使用](../creative.md#method-use)。

## 从事件长出拍法

先找这一段真正发生的变化：人物做成了什么、失去了什么，或观众对同一件事有了什么不同理解。再找造成变化的行动。宣布“我决定走了”与真的把钥匙放回桌上、绕过对方走向门口，承担的观看过程不同；两者都可用，按本片要看的选择。

把观众需要的事实安排在动作发生之前或之后：先见证据再看反应，观众与人物一起认出，或先看反应后揭原因。选择会改变悬念、喜剧和情感距离，同时决定构图、遮挡、景深、声音与切点。摄影在这里参与创作，不等故事写完才装饰。

目标与阻力参与故事时，写成具体的应对链：想把什么交给谁，对方怎样阻止，人物怎样调整行动，结果改变了什么。不是每段都要新阻力；兑现、等待、僵持或余韵可以有自己的作用。关系需要通过空间表达时，选择谁靠近、谁让出位置、谁先动；普通注意力转移不用解释成权力变化。

行动或转变缺少人物自身的原因时，用[人物驱动力](../techniques/performance.md#character-drive)发展他想争取、舍不得损失及因此采用的办法，再落实到同一段表演。

<a id="dilemma"></a>

## 确实要表现两难时

只有本片要让观众感受“选哪边都舍不得”时才用。普通决定、单向追求或非叙事表演不需要补成两难。

让两条路直到行动前都仍可走、仍有价值，并交代为什么不能兼得：同一时刻只能接住一件东西、有限资源只够完成一项，或一个公开行动会破坏另一项承诺。若一边早已不可能、无价值，或其实可以先后完成，先修具体条件；也可以按作品本意保留为普通决定，不用追加灾难硬做深刻。

选择后让观众看见它新增或加重的损失：换另一条路，这项损失是否就不会发生？原本无论如何都会遇到的困境可形成压力，却不重复算成这次选择的代价。回报可以与损失并存，可兼得的收益不必一起扔掉；已成为核心阻力的损失，不在结尾自动复位。

例如决胜球滚向右侧门角，对方前锋同时失衡撞向左侧门柱；守门员已经朝右侧球路起动，却改向左侧接住前锋，让球越过门线。取景先同时交代两侧和守门员距球仅一步的扑救机会，再跟随他改向接人的动作；球入网、哨声和仍留在网中的球让失球没有被救人后的庆幸抹去。若要表现他真的犹豫，还须给可读的反应时间，不把瞬间本能写成长时间权衡。此为原创方法示例。

取舍来自已建立的目标、关系和现场事实；新信息可以改变判断，最终回应仍由人物作出。发现“两难不成立”时，回修选择前的条件、动作或后果，不靠补一句“他很纠结”。

<a id="story-constructions"></a>

## 四种可选构造

这些方法按问题选用，不要求叠加。

| 构造 | 怎样发展 | 声画怎样参与 |
| --- | --- | --- |
| 失效的职业办法／错误优势 | 人物认真使用自己熟练的办法，恰好使眼前目标更难实现。先让观众懂他为何觉得有效，再看办法怎样反噬；若真的解决了需求，就不是此类错位。 | 保留专业动作的可信过程及失效处，摄影同时交代工具、对象和后果。声音可维持严肃操作感，让结果自行出笑点。 |
| 递进问答 | 每次问答改变事实、解释范围、态度或关系；重复、停顿和答非所问也可承担节奏，不固定轮数。 | 发问与回答不必机械正反打。让答话触发一次转头、交物或空间变化；答案的声源也可以先在画外出现。 |
| 正式确认荒谬 | 用认真的身份、程序和措辞，把不可能的事当作日常业务完成。关键是异常确实进入行动，不停在设定名词。 | 让正常操作与异常对象同框可读。盖章、递单、点头等声音和动作完成确认，不必加旁白解释。 |
| 后来的事实重写前面的理解 | 先建立可信表态或行动，之后出现事实，让此前的感谢、承诺、自夸或帮助变了意思。 | 给新事实实际出现的路径和足够辨认时间；镜头移动、焦点交接、声音来源都可承担揭示。换表情或补字幕不自动构成改义。 |

例如“山门验收员认真核对刚被修士削平的山峰”：开场不是一句“荒谬的验收”，而是验收员将水平尺放上削痕，修士紧张地扶住尺子；相机沿尺身横移，露出整座山也被削出了同一条水平线；验收员划过勾选框说“偏了一点”，修士又举起剑。专业动作、尺度揭示和下一次行动共同形成过程。此为原创构造示例，不是已生成案例。

<a id="dialogue"></a>

## 台词、反应与表演

一句台词至少要在当下起作用：告知、争取、拒绝、试探、安抚、逗弄，或让人享受语言本身的节奏。用人物的场合、关系和行动选择语气，不用一长串情绪词代替可演过程。台词属于谁、对谁说、从画内还是画外发出、说话时在做什么，要能分清。

反应可按“听到/看到 → 认出或误解 → 身体回应 → 接下来的行动”设计，但只保留本片需要的阶段。反应可以大笑、冲上前、挥手打断、全身退缩，也可以停顿或细微动作；幅度由风格、景别和人物决定。不要在没有掩饰意图时添加“强忍”“微微”。

潜台词只在表面表达与实际目的有差距时使用。例如人物说“你先走”，同时把对方的伞收回自己手边；观众要看见这件相互矛盾的事。坦率表达无需再造秘密。压抑行为也只在压抑存在时成立，不能成为所有戏的通行证。

两人对话可以在同镜头中完成，前提是关键行动与反应有观看位置；切镜应带来不同信息、距离或节奏。完整发声、不能并发的动作及必要停顿共同占时。写各自会说的话看[角色语言](../techniques/music-and-sound.md#character-voice)，发声安排看[对白与声音](../techniques/music-and-sound.md#dialogue)、[同步与时间](../techniques/music-and-sound.md#sync-text)，表演推进看[连续表演](../techniques/performance.md#continuous-performance)。

## 声音与物件也能叙事

选择属于这次事件的细节：门闩声让人物知道有人回来；杯底留下的水圈证明物件被挪过；外面呼喊突然停下改变室内人的行动。细节应改变理解或行动，不靠给普通道具加编号制造独特感。

留白说明让谁停、让什么继续，以及何时恢复。可以撤去人群闲谈，让仍在转动的机器声暴露人物没关设备；也可以让人物继续高声说笑，背景脚步越来越近。声音不总要和画面同情绪，具体分工见[声画反差](../techniques/music-and-sound.md#counterpoint)。

## 组合与结束

需要观众发笑时借[喜剧](comedy.md)安排预期和时机；需要延迟确认时借[悬疑](suspense.md)安排信息；有歌舞或动作时，故事变化应由完整身体过程承载，不以一句台词替代。没有这种故事目标的表演，直接用其相应方法。

结尾可以完成选择、改变关系、留下新问题或停在余韵。它需要兑现本片约定的观看过程，具体状态用[结束用途](../shooting-treatment.md#endings)决定，不必统一落在最后一帧反转。

本方法失效的信号：情节只在解释中成立；决定只被宣布而未执行；关键新事实一闪而过；反应先于人物可能知道的事；有用过程被重复说明挤掉。修相应行动、信息位置或声画时间，不靠补满心理字段解决。
